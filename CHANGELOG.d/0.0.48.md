# GTT 0.0.48 — Native Fieldmaster Collision & Breakdown Integration

## Added
- Native Fieldmaster `NotifyHit` collision callback wired into the shared gameplay condition/tire snapshot.
- Impact-speed estimation using vehicle velocity plus physics impulse/mass fallback.
- Short collision-damage cooldown to prevent one sustained contact from becoming many duplicate damage events.
- Immediate native breakdown response that clears throttle/steering and applies braking at zero condition.

## Changed
- Severe Native Fieldmaster impacts now degrade tire integrity in addition to body condition.
- Collision mutations synchronize promptly into the hidden legacy compatibility mirror so save/load, workshop, tuning and heavy-haul payout consume the same state.
- Low-speed contacts and inactive Native takeover remain damage-free.
