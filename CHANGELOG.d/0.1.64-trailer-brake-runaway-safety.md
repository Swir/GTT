## GTT 0.1.64 — Trailer Brake Runaway Safety

- Added hysteretic trailer-brake thermal states (`Normal`, `Hot`, `Fading`, `Critical`) so HUD/audio consumers can warn the driver without flickering around heat thresholds.
- Added a narrow, bounded runaway-mitigation path for throttle-off, fast, steep, heavily loaded descents while trailer brakes are critically hot.
- Emergency mitigation adds only a small tractor-side brake contribution (0.08–0.20 before load scaling); it never steals drivetrain direction, never bypasses the existing brake ownership path and releases when the driver deliberately applies throttle.
- Preserved 0.1.63 thermal fade/recovery, 0.1.62 hill-haul behavior, 0.1.59 heavy-haul authority and final shared drivetrain ownership.
- Exposed thermal state, mitigation-active and safety-brake telemetry for concise HUD/audio integration and packaged playtest evidence.
- Added deterministic source/math verification and regression CI. This source milestone does not claim UE 5.8 / Win64 runtime acceptance and does not close any of the five remaining roadmap gates.
