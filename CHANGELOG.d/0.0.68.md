# GTT 0.0.68 — Native Road Traffic Incidents & Wanted Escalation

## Added

- New `UGTTNativeRoadIncidentSubsystem` automatically watches active Native Rattleback 82 / Mulebox 1200 takeovers for fresh, already-authoritative Native impact events.
- Native road pawns now expose read-only impact evidence (`GetNativeImpactCount`, `GetLastImpactSpeedKmh`) so other gameplay systems can consume real crash events without duplicating collision physics.
- Traffic incidents are spatially attributed to a nearby civilian `AGTTTrafficCarPawn` within a bounded radius after a new Native impact.
- Civilian traffic victims now receive shared body damage, plus tire damage for severe impacts, through the existing vehicle damage model.
- Player-caused Native traffic collisions add heat to the hidden driver's existing `UGTTWantedComponent`, feeding the established police escalation/decay loop instead of creating Native-only crime state.
- Loaded Mulebox incidents add a small cargo-related heat consequence, complementing the existing cargo-inertia self-damage and farm-job reward penalties.
- Runtime evidence: `NATIVE_ROAD_TRAFFIC_INCIDENT`, `NATIVE_ROAD_CRIME_ESCALATION`, and a no-traffic diagnostic for avoiding false crime attribution.

## Changed

- Road-fleet crashes now affect both sides of a traffic collision: the player's Native vehicle retains 0.0.67 persistent self-damage while the civilian victim can now be damaged as well.
- Police escalation can now originate from reckless Native road driving when a real traffic victim is involved.
- Incident processing is deduplicated by Native impact count so sustained contact cannot add wanted heat every scan tick.
- Roadmap remains exactly `125/130 (96.2%)`; no runtime-only Native Chaos or Win64 checkbox is closed by source-level integration.

## Verification

- Added `Scripts/verify_native_road_incidents.py` and wired it into Project sanity.
- Added `Docs/PLAYTEST_0.0.68.md` covering world-collision regression, civilian traffic damage, wanted escalation, event deduplication, loaded Mulebox consequences and fallback safety.
- The verifier recalculates the Roadmap checklist/dashboard contract and enforces `SWIR-ROADMAP-STANDARD:v1`.

## Known limitation / Demo status

This is source/runtime implementation and CI-contract work. It is **not** proof of a compiled Unreal Engine 5.8 Win64 game. The first Demo Release remains blocked until a real Win64 package is produced, the packaged executable passes runtime smoke testing, visual acceptance passes, relevant CI is green, and no demo-critical blocker remains.
