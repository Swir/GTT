# 0.0.53 — Native Fieldmaster Drive Dynamics

## Added
- `UGTTNativeDriveDynamicsSubsystem` for active Native Fieldmaster takeovers.
- Damage/tuning-aware native speed envelope using shared condition, tire integrity and engine/tire upgrade state.
- Progressive damaged-tire rolling drag and critical breakdown braking.
- Periodic `NATIVE_DRIVE_DYNAMICS` runtime evidence.
- `PLAYTEST_0.0.53.md` and `verify_native_drive_dynamics.py` coverage.

## Changed
- Native Fieldmaster driving now reacts to the same persistent gameplay state used by workshop, tuning, save/load and heavy-haul systems instead of always behaving like a pristine tractor.
- Critical condition and empty fuel now force a safe native stop through the Chaos movement component.

## Limitations / Next
- No UE 5.8 Win64 package/runtime was available in this repository iteration, so no packaged EXE or visual demo acceptance is claimed.
- Native Chaos roadmap items remain open until authored rig, wheel/suspension/contact behavior and packaged runtime evidence are actually verified.
