# GTT 0.0.82 — Deterministic Packaged Demo Scenario

- Added an opt-in `UGTTDemoSmokeScenarioSubsystem` activated only by `-GTTDemoSmokeScenario`; normal player sessions are unchanged.
- Packaged smoke now actively verifies world/GameMode, HUD, traffic director, civilian NPC presence, active mission, wanted component availability and a real SaveGame write before emitting `DEMO_SCENARIO_COMPLETE result=PASS`.
- Added `DEMO_SCENARIO.json` with explicit per-step PASS evidence bound to the same runtime/build SHA.
- Win64 evidence pipeline now runs the deterministic scenario before generic gameplay evaluation and retains its manifest in the candidate artifact.
- Demo technical gate schema 3 requires deterministic scenario PASS in addition to runtime survival, packaged gameplay smoke and fleet-wide Native Chaos smoke-ready evidence.
- Added Project sanity coverage for the scenario source/runtime/workflow contract.

No roadmap checkbox is closed: this source milestone still requires a genuine UE 5.8 Win64 compile/package/runtime execution, and public demo release still additionally requires rendered visual acceptance.
