## GTT 0.0.66 — Native Road Fleet Takeover Foundation

### Added
- Shared `AGTTRoadVehicleNativePawn` takeover layer for Rattleback 82 and Mulebox 1200 instead of duplicating the Fieldmaster-specific migration path.
- Acceptance-gated Native Chaos configuration for each road vehicle: rig bones/sockets, canonical wheel setup, canonical powertrain and Physics Asset must all validate before legacy gameplay is replaced.
- Automatic road-fleet native candidates through `UGTTNativeFleetTakeoverSubsystem`; candidates stay hidden and harmless while authored runtime requirements are missing.
- Full legacy gameplay-state handoff for condition, fuel, ownership, engine/tire tuning and tire integrity, with continuous mirror sync so existing garage/save systems remain authoritative.
- Runtime revalidation and `NATIVE_ROAD_FALLBACK` restoration of the legacy pawn if the native setup becomes invalid after takeover.
- Native Mulebox cargo integration: the existing farm contract can load/unload the accepted Native Chaos van, retain its role bonus and make cargo condition-sensitive without using the hidden legacy mirror as the active job vehicle.
- Native road fuel burn, condition/tuning power response and tire-integrity/tuning steering response.
- `PLAYTEST_0.0.66.md` and `verify_native_road_fleet_takeover.py` Project sanity coverage.

### Gameplay
- Once authored Rattleback/Mulebox skeletal rigs pass the same runtime gates as Fieldmaster, ownership in the existing garage can promote those vehicles to the Native Chaos path without losing fuel, damage or tuning state.
- Native Mulebox remains part of the legal cargo loop instead of becoming a disconnected technical vehicle test.
- A failed runtime acceptance check restores the legacy road vehicle instead of trapping the player in a broken Native Chaos pawn.

### Limitations
- This milestone deliberately does **not** mark Native Chaos roadmap items complete: the repository still lacks genuine UE 5.8 / packaged Win64 runtime acceptance and final authored skeletal road-vehicle assets.
- No Windows demo release is justified until package, EXE smoke and visual acceptance gates are actually passed.
- Roadmap remains 125/130 (96.2%).
