# GTT 0.1.60 — Authored Trailer Source Rig

## Added
- Added the first deterministic, project-owned farm-trailer skeletal source generator producing a self-contained glTF 2.0 import candidate.
- Added authored `body`, `wheel_l`, `wheel_r` joints and explicit hitch/cargo/axle anchor nodes.
- Added original trailer body, drawbar, rails/fenders and dual-wheel geometry with project-owned paint/tire materials.
- Added cross-runner-stable wheel quantization plus a source-contract verifier for rig hierarchy, embedded-buffer safety, dimensions, originality metadata and same-runner byte-for-byte regeneration.
- Added dedicated GitHub Actions coverage and an Unreal import/runtime acceptance checklist.

## Release-gate truth
This milestone materially advances the `Authored skeletal trailer wheel assets and final hitch sockets` blocker, but does not mark it complete. The generated glTF candidate still must be imported into UE 5.8, receive final Unreal sockets/PhysicsAsset wiring, replace the accepted placeholder presentation path, pass the existing authored-trailer packaged runtime evaluator and pass rendered visual review on the exact Win64 candidate. Roadmap truth therefore remains 125/130 (96.2%).
