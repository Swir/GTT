# GTT 0.1.7 — Interactive Dispatchers & Rural Order Negotiation

## Added
- Interactive logistics staff: the Feed Dispatcher, Hill Receiver and Wood Foreman now implement the normal GTT interaction interface instead of acting only as scheduled world decoration.
- Feed Dispatcher order negotiation that lets the player cycle among every currently fulfillable CARGO tier allowed by reputation, depot stock and destination demand. A RELIABLE driver can therefore deliberately choose T1 direct, T2 relay or T3 bulk work when all three are genuinely available.
- Distinct risk/reward descriptions for each choice: T1 uses 2 units and the short Hill Farm route, T2 uses 3 units and the Hill/Wood relay with the existing +$70 chain bonus, and T3 uses 4 units, the existing +$120 chain bonus and the existing 1.20 heavy cargo-load handling penalty.
- Live dispatcher briefings: Hill Receiver reports current Hill demand and selected order; Wood Foreman reports Wood demand, backlog pressure and the shared ROAD/CARGO supply signal.
- Same-day negotiated-order persistence in the additive schema-v8 logistics snapshot (`CargoNegotiatedOrderTier`, `CargoNegotiationDay`).
- Compact world-space staff prompts (`E NEGOTIATE`, `E STATUS`) instead of adding another permanent HUD/debug wall.
- `Scripts/verify_interactive_dispatch_negotiation.py` plus `Docs/PLAYTEST_0.1.7.md`, wired into Project sanity.

## Changed
- `GetActiveCargoOrderTier()` now means the actual order the player will receive: a valid explicit dispatcher choice first, otherwise the 0.1.6 living-market recommendation. Existing contract-board and farm-director consumers therefore inherit negotiation without duplicate mission state.
- Negotiated choices automatically invalidate if stock/demand/reputation can no longer fulfill them, expire when the next work day begins, and clear after a completed or failed CARGO run.
- The existing Contract Board continues to show `CAP Tn / ORDER Tn`, exact unit count, priority, stock/demand and reward range; `ORDER` now reflects the negotiated choice when one is active.
- Rural staff remain schedule-bound to 07:00–17:30. Off-shift interaction cannot mutate order selection.
- SaveVersion remains 8 because the negotiation fields are additive with safe zero defaults. Existing v8 profiles continue to load without destructive migration.
- Roadmap remains exactly **125/130 (96.2%)**. This source/gameplay milestone does not close any Native Chaos authored-asset, trailer, Win64 package, packaged-runtime or visual-acceptance gate.
