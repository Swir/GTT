# GTT 0.1.33 — Packaged Farm Cargo Breakdown Recovery Evidence

## Added

- Added `UGTTFarmCargoBreakdownEvidenceSubsystem`, an opt-in packaged-smoke route that uses the real native Mulebox, Farm Cargo terminals, exact cargo authority, Breakdown Decision subsystem and player-authorized Roadside Recovery service.
- Added deterministic proof for a disabled native cargo vehicle: exact-ID pickup, native damage, paid tow, timer continuity, no cargo-integrity improvement, preserved damage, wrong-vehicle rejection after tow, Hill Farm relay, North Wood Yard completion, payout/reputation and final save.
- Added `evaluate_farm_cargo_breakdown_runtime.ps1`, producing `FARM_CARGO_BREAKDOWN_RUNTIME.json` with schema `gtt.farm-cargo-breakdown-runtime.v1` only when phase evidence, production recovery markers and final completion values agree.
- Added 80-scenario manual/runtime playtest coverage and a dedicated source-contract verifier/workflow.

## Changed

- Packaged runtime smoke now explicitly enables `-GTTFarmCargoBreakdownScenario` after the existing Farm Cargo save/load recovery route.
- The Win64 evidence window is extended so the breakdown/tow route runs after earlier deterministic scenarios rather than overlapping them.
- Demo technical evaluation now requires the breakdown-recovery JSON in addition to base Farm Cargo and mid-route save/load evidence.
- Native vehicle evidence cleanup can restore a captured migration snapshot and mirror it back to the legacy fleet actor, avoiding evidence-only tire/condition damage leaking into the restored baseline.

## Verification / release truth

- Roadmap completion remains **125/130 (96.2%)**. This source milestone does not close Native Chaos, authored-trailer, packaged Win64 or visual acceptance gates.
- Source-contract CI verifies wiring, anti-bypass rules and evaluator requirements. It **does not prove** that Unreal Engine 5.8 compiled the new C++ or that a packaged Windows EXE executed the route.
- `FARM_CARGO_BREAKDOWN_RUNTIME.json` is authoritative only when produced from the exact packaged candidate on a qualifying Windows x64 + UE 5.8 runner.
- Public demo release remains blocked until all technical and visual gates pass on the exact candidate.
