# GTT 0.0.86 — Wanted-4 Roadblock & Interception Proof

## Added
- Deterministic packaged scenario now escalates the real wanted component to level 4, crossing the existing roadblock escalation threshold.
- Runtime proof requires an active police roadblock, not merely a configured roadblock class.
- Runtime proof also requires the Police Director's road-node interception state and records the selected interception node label.
- `DEMO_SCENARIO.json` schema v5 hard-gates 23 milestones spanning world, fleet control, pursuit closing, roadblock deployment, interception and save.

## Changed
- Win64 evidence workflow advances to 0.0.86 and evaluates the wanted-4 roadblock/interception route.
- Crime injection remains opt-in behind `-GTTDemoSmokeScenario`; normal sandbox wanted progression is unchanged.
- Existing vehicle-control and pursuit-closing gates remain mandatory, so escalation evidence cannot replace earlier gameplay proof.

## Limitations / Next
- Source sanity validates the contract only. Roadblock placement, interception behavior and Native Chaos execution still require a real packaged UE 5.8 Win64 run.
- Demo Release remains blocked until Win64 package/runtime evidence and rendered visual acceptance both pass.
