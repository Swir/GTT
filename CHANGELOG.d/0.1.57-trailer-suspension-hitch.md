### GTT 0.1.57 — physical trailer suspension and hitch dynamics

- Added a runtime trailer-dynamics subsystem that gives the physical farm-trailer wheel constraints bounded vertical suspension travel with load-sensitive spring and damping tuning.
- Added a physical breakable hitch whose force/torque threshold reacts to cargo, trailer integrity and live hitch stress; a real physics break routes through the existing authoritative detach path instead of creating a second cargo/damage authority.
- Added runtime telemetry/snapshot support plus deterministic CI/source verification and an explicit Unreal runtime playtest contract.
- Roadmap completion remains 125/130 (96.2%): authored skeletal trailer wheel/final hitch assets, native Chaos acceptance and Win64 packaged/runtime gates are still open and are not claimed by this source milestone.
