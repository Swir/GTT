# GTT 0.0.75 — Native Drivetrain Authority

## Added

- Shared Native Chaos drivetrain safety authority for **Rusty Fieldmaster 60**, **Rattleback 82** and **Mulebox 1200** inside the existing `UGTTNativeDriveDynamicsSubsystem`.
- Speed-gated forward/reverse direction interlock that cuts throttle and applies progressive braking instead of allowing an instant high-speed `1 <-> -1` gear swap.
- Low-speed shift commit after the vehicle has decelerated below the safe release threshold.
- Neutral engine braking plus a low-speed stationary/hill hold shared by the Native fleet.
- Runtime evidence through `NATIVE_DRIVETRAIN_AUTHORITY_EVIDENCE`, `NATIVE_DIRECTION_INTERLOCK` and `NATIVE_DIRECTION_SHIFT_COMMIT`.
- Dedicated 0.0.75 playtest and source sanity verifier.

## Changed

- The existing Fieldmaster drive-dynamics subsystem now also supplies the final drivetrain safety layer to the Native road fleet instead of leaving forward/reverse authority duplicated in each pawn.
- Vehicle-specific power, cargo, tire, body-damage, steering and traction scaling remain upstream and continue to define each vehicle's handling; the new authority only overrides commands when a safe direction change, neutral engine braking or stationary hold requires it.
- Direction-change interlock temporarily reduces steering input while braking, avoiding full-lock snap turns during a high-speed requested reversal.
- Roadmap remains exactly **125/130 (96.2%)**. This is substantial source/runtime architecture progress, but it does not claim the two remaining Native Chaos checklist items are complete without authored-asset UE 5.8 runtime evidence.

## Limitations / Next

- Repository CI can verify the source contract and integrations, but the current runner still cannot prove a full Unreal Engine 5.8 Win64 compile/package/runtime smoke test.
- Native vehicle asset/runtime acceptance remains required before either Native Chaos roadmap checkbox can honestly close.
- The first public demo remains blocked until a packaged Win64 EXE is built and smoke-tested and the rendered game passes visual acceptance.
- Next large package should extend the shared authority with runtime wheel/axle drivetrain evidence and authored suspension acceptance, then feed that evidence into the remaining Native Chaos closure gates.
