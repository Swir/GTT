# GTT 0.1.43 — Workshop Hours & After-Hours Recovery

## Added

- Connected the existing workshop to the authoritative `AGTTDayNightCycle`: regular repair/refuel hours are now 06:30 inclusive through 20:00 exclusive.
- Added `GTTWorkshopHoursPolicy` as the single source for opening/closing boundaries, display text and the emergency recovery surcharge.
- Added an after-hours recovery lane only for vehicles already under a hard `WORKSHOP HOLD` (`TOW` / `IMMOBILE`), preventing a nighttime soft lock after roadside recovery.
- Emergency recovery uses the existing authoritative damage-based repair quote plus a deterministic **35% surcharge**, rounded up, and then uses the same repair/refuel/save path as daytime service.
- Added Blueprint-friendly workshop OPEN/CLOSED status and native-road checkout quote APIs so future HUD/presentation can read the production rule rather than reimplementing it.
- Garage office messaging now surfaces current workshop availability, schedule and the after-hours hold-recovery rule before the player reaches the service terminal.

## Changed

- Ordinary damaged/mobile repair and fuel-only service now wait for opening when the world clock says the workshop is closed; rejection occurs before economy debit or vehicle mutation.
- Native road, Native Fieldmaster and legacy fleet service share the same schedule behavior, while a genuine hard hold retains an emergency escape path.
- A missing day/night actor intentionally fails open so stripped test maps cannot permanently lock vehicle service.
- The historical 0.1.41 verifier now accepts later current-development milestones while still requiring the original garage-hold contract and README evidence.

## Verification

- Added `Scripts/verify_workshop_hours_emergency_service.py`, a dedicated GitHub Actions workflow and a 78-scenario playtest covering schedule boundaries, economy ordering, emergency surcharge, garage UI, hold release, Farm Cargo continuity and release honesty.
- The new workflow re-runs the 0.1.41 garage/workshop contract, the 0.1.42 packaged workshop-evidence contract and deterministic SWIR SVG progress validation.
- Roadmap completion remains **125 / 130 (96.2%)**. This connected gameplay/economy milestone does not close Native Chaos, authored-trailer, Win64 build/package/runtime or visual demo gates.
