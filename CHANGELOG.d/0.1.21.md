# GTT 0.1.21 — Warden enforcement, police handoff and night poaching risk

This milestone pivots back from release-gate infrastructure into the live sandbox loop. It expands the previously thin game-warden response into a connected enforcement system and fixes the mismatch where forest poaching created rural contraband but a successful warden stop did not seize it.

## Connected ranger / police enforcement

- `AGTTRangerDirector` now exposes an explicit enforcement tier and tracks whether the current wildlife incident has triggered a cross-agency police handoff.
- Wildlife alert 3 performs a one-shot handoff into the existing `UGTTWantedComponent` instead of creating a second disconnected police meter. The handoff adds bounded wanted heat and gives the player a clear `WARDEN RADIO HANDOFF` message.
- The handoff is armed once per wildlife incident and resets only after wildlife heat returns to zero, preventing the director's one-second response loop from stacking police heat every tick.
- Alert 3 still fields the existing two-ranger maximum. At night, alert 2 can also deploy a second ranger, making after-dark illegal work materially harder without spawning an unbounded crowd.

## Contraband now has a real enforcement consequence

- `UGTTRuralEconomySubsystem` now provides an authoritative confiscation operation that clears both contraband units and their stored fence value and persists the change immediately.
- A successful ranger citation now confiscates the same contraband inventory produced by `AGTTForestPoachingSpot`, with a player-visible seizure report showing lost units and estimated fence value.
- Existing citation fines, wildlife-alert clearing, police wanted logic and save behavior remain authoritative; the new path integrates with them rather than replacing them.

## Night poaching risk / reward

- Forest poaching now reads the real `AGTTDayNightCycle` state.
- Night attempts apply 1.25x wildlife heat, making warden escalation and the police handoff arrive sooner.
- Successful night poaching applies 1.18x estimated fence value, so the higher enforcement risk has a bounded economic reward rather than being pure punishment.
- Night-specific player feedback makes the tradeoff readable in the existing message UI.
