# GTT 0.1.24 — Enforcement presentation, civilian roadside behavior and lane-aware traffic

## Gameplay

- Warden vehicle stops now expose a compact COMPLY / SEARCH / FLEE presentation snapshot to the game HUD instead of relying on transient economy messages or raw status strings.
- COMPLY shows a single bounded progress bar plus a direct pull-over/hold instruction; SEARCH reuses the same panel for hold progress; FLEE switches the panel to police-escalation feedback for its existing short display window.
- Nearby civilian NPCs now react to a live roadside stop. Civilians inside the protected road corridor step toward a deterministic safe lateral point instead of wandering through the ranger/player contact.
- Civilians already outside the lane can pause and observe the stop, then return to their normal day/night schedule after enforcement clears.
- Combat, hostile-faction and knocked-out behavior keeps priority over the civilian roadside reaction so enforcement presentation cannot neutralize active fights.
- Ambient traffic is now lane-aware: only vehicles travelling in the same direction as the stopped player receive the existing slowdown/hold response. Oncoming traffic in the opposite lane is allowed through rather than being frozen by proximity alone.

## Integration

- Added `FGTTRangerRoadStopPresentation` and `GetPresentationSnapshot()` to `UGTTRangerRoadStopSubsystem`; the same world authority now feeds ranger staging, traffic response, civilian scene response and HUD state without duplicating Wanted, citation or contraband ownership.
- `AGTTGameHUD` renders a small dark/cyan/orange/red enforcement panel with one phase heading, one instruction and one progress bar. The panel is transient and does not add another permanent debug block to the screen.
- `AGTTCitizenPawn` promotes nearby road-stop witnesses to urgent world-simulation cadence, clears them out of the lane when required, lets safe bystanders observe, and restores schedule wandering when the stop ends.
- Existing `AGTTTrafficCarPawn` physical braking, queue behavior, crash priority and stuck-recovery suppression remain the only traffic execution path; 0.1.24 only improves the shared lane-selection decision upstream.
