# GTT 0.1.34 — Roadside Emergency Patch & Farm Cargo Recovery Choice UX

## Added

- Added a paid, player-authorized **emergency roadside patch** for native road vehicles as a genuine alternative to towing when damage is mechanical/tire/fuel related and the structural/body state is still safe enough for a temporary limp-home fix.
- Added deterministic patch pricing to the existing breakdown assessment and HUD: the quote is separate from tow and full workshop repair.
- Added a dedicated Farm Cargo recovery-choice HUD panel that keeps the exact cargo vehicle identity, recovery state, contract-clock consequence and available patch/tow choice visible without turning the general HUD into debug telemetry.
- Added Farm Cargo save checkpoints immediately before and after a successful emergency patch, with exact `PersistentVehicleId` verification and anti-transfer logging.
- Added source-contract verification, a dedicated GitHub Actions gate and a 64-scenario playtest matrix for patch/tow/cargo integration.

## Changed

- Fixed a real recovery UX/authority mismatch: `TowRecommended` now permits an explicit player tow choice at low speed instead of the HUD advertising `T CALL TOW` while the recovery subsystem silently rejected anything short of full immobilization.
- Police auto-impound remains limited to genuinely stranded native vehicles; broadening the voluntary recovery choice does not broaden automatic police recovery.
- Roadside patch restores only minimum limp-home floors (30% condition, 32% tires, up to 5 L emergency fuel). It does **not** restore body damage, detached panels, upgrades, cargo identity or full workshop condition.
- Patch and tow requests are mutually exclusive and both remain blocked while wanted heat is active.
- Active Farm Cargo never transfers the load to another vehicle during patch/tow recovery, and its delivery timer intentionally continues running.

## Verification / release truth

- Roadmap completion remains **125/130 (96.2%)** because this milestone does not close Native Chaos, authored-trailer or Win64 runtime/build acceptance.
- Source CI validates wiring, recovery-choice invariants, anti-transfer/save checkpoints and the existing 0.1.32/0.1.33 contracts.
- This milestone does **not** claim a real UE 5.8 Win64 compile/package, packaged-EXE smoke test, rendered visual acceptance or public demo readiness.
