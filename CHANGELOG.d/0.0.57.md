# GTT 0.0.57 — Native Load Transfer & Grade Response

## Gameplay
- Native Fieldmaster stability now estimates front/rear and left/right chassis load transfer from the four canonical wheel-ground clearances.
- Heavy trailer load amplifies unsafe rearward bias instead of affecting only sway and payout.
- Terrain pitch is folded into the chassis risk model so steep grades become part of the same driving-control loop.
- Sustained unsafe load transfer has its own grace period and can cut throttle, add proportional braking, and suppress steering under severe lateral imbalance.
- Existing tire upgrades still reduce intervention strength slightly, but cannot cancel severe load-transfer protection.

## Runtime evidence
- `NATIVE_STABILITY_EVIDENCE` now includes `load_transfer`, `front_rear_bias`, `side_bias`, and `load_transfer_s` so UE 5.8 playtests can distinguish airborne/contact risk from weight-transfer risk.
