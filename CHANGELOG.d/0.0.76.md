# GTT 0.0.76 — Native Wheel/Axle Traction Authority

## Added

- New shared `UGTTNativeAxleTractionSubsystem` for Rusty Fieldmaster 60, Rattleback 82 and Mulebox 1200.
- Live front/rear/left/right contact accounting from actual Chaos `FWheelStatus` records.
- Front/rear slip-risk sampling from slip magnitude, slip angle, slipping and skidding flags.
- Suspension-derived left/right load proxies and axle-imbalance evidence.
- Severe unsupported/slipping axle torque cut, progressive brake assist and bounded grounded yaw correction.
- Tire-integrity and tire-upgrade weighting so the authority remains connected to the existing tire/workshop economy.
- Runtime evidence through `NATIVE_AXLE_TRACTION_EVIDENCE` and `NATIVE_AXLE_TRACTION_INTERVENTION`.
- Dedicated playtest documentation and Project sanity verifier.

## Changed

- Native Chaos vehicle safety now has a common wheel/axle authority layered after the existing vehicle-specific handling systems instead of relying only on whole-vehicle speed and direction state.
- The subsystem only removes drive authority under unsafe wheel evidence; it does not add grip, teleport vehicles or replace the existing 0.0.75 direction-change authority.
- Road-fleet body damage, Mulebox cargo penalties, Fieldmaster heavy-haul/terrain systems, tire wear and workshop repair remain upstream and continue to affect the final driving result.

## Validation / limitations

- Repository sanity can verify the source contract and gameplay integration, but the current available runner still does not prove a full Unreal Engine 5.8 Win64 compile/package or packaged-EXE runtime smoke test.
- Roadmap therefore remains **125/130 (96.2%)**; neither remaining Native Chaos checkbox is closed from source-level evidence alone.
- No Demo Release should be created until a real packaged Windows build passes launch/runtime smoke, rendered visual acceptance and all relevant CI gates.
