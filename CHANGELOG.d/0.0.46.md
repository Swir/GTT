## [0.0.46] - 2026-09-13 — Native Fieldmaster Workshop & Tuning Integration

### Added
- Native-aware workshop routing so an active `AGTTFieldmasterNativePawn` is serviced as the visible gameplay vehicle instead of treating its hidden legacy compatibility mirror as an independent target.
- Native-aware tuning routing covering tire repair, engine upgrades and tire upgrades with the existing economy prices, upgrade caps and save flow.
- Immediate compatibility re-import after every successful workshop/tuning mutation, preventing the 0.0.45 periodic mirror sync from overwriting newly purchased repair, fuel or tuning state.
- Transaction rollback for native service/tuning synchronization failures so the player is not charged for a state change that could not be transferred safely.
- `PLAYTEST_0.0.46.md` and dedicated sanity coverage for workshop/tuning persistence, hidden-mirror target safety and roadmap honesty.

### Changed
- When Native Fieldmaster takeover is active, generic legacy workshop/tuning searches skip the hidden `RustyFieldmaster60` mirror; Rattleback 82 and Mulebox 1200 continue using their existing legacy service path unchanged.
- Existing `AGTTVehicleBase` repair/refuel/tuning methods remain the canonical implementation during migration, avoiding duplicate upgrade caps, fuel capacity or vehicle-service rules in the Native pawn.
- Roadmap remains exactly `125/130 (96.2%)`; this closes a real gameplay-loop migration regression but does not claim authored Native Chaos runtime acceptance.

### Limitations / Next
- The repository still lacks the authored Fieldmaster skeletal mesh/Physics Asset needed to instantiate and drive this takeover path in the current build.
- No self-hosted Windows x64 Unreal Engine 5.8 evidence run has verified a packaged `GTT.exe`; no demo Release is created.
- Next major package should extend Native Fieldmaster integration into collision/damage/terrain/trailer gameplay state or supply the authored asset/runtime path if an Unreal-capable runner becomes available.
