# GTT 0.1.42 — Packaged Workshop Recovery + Farm Cargo Service Evidence

## Added

- Added an opt-in packaged Farm Cargo evidence route for the 0.1.41 garage/workshop recovery contract.
- The route accepts a real feed contract, binds the exact native Mulebox, damages it into `TowRecommended`, authorizes the production roadside tow and observes the request-time locked quote without pre-charging cash.
- After the real tow completes, the route verifies one exact tow debit, preserved damage, preserved `PersistentVehicleId`, preserved Farm Cargo authority and arrival at the actual workshop district.
- Added runtime proof that authoritative `TOW` / `IMMOBILE` fleet state produces a hard `WORKSHOP HOLD` after ordinary damage-preserving tow.
- The evidence route attempts the actual numbered garage-bay recall while held and requires rejection before vehicle movement and before the recall fee can be charged.
- The same route then invokes the existing native workshop terminal, observes the damage-based quote, requires one exact workshop debit, full mechanical repair/refuel, natural hold release and unchanged exact cargo-vehicle authority.
- After service, a decoy vehicle must still be rejected before the exact Mulebox completes Hill Farm and North Wood Yard with one payout, one cargo completion, reputation gain and final save.
- Added `Scripts/evaluate_farm_cargo_workshop_recovery_runtime.ps1`, producing `FARM_CARGO_WORKSHOP_RECOVERY_RUNTIME.json` (`gtt.farm-cargo-workshop-recovery-runtime.v1`) only from packaged runtime PASS markers.
- Added `Scripts/promote_demo_gate_workshop_recovery.ps1`; after the existing schema-12 demo evaluator passes, a future candidate must also satisfy the workshop recovery manifest before `DEMO_TECHNICAL_GATE.json` is promoted to schema 13.
