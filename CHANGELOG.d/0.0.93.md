# GTT 0.0.93 — Persistent Native Structural Damage

## Added
- Native road vehicles now persist exact four-zone body health, cooling stress and a four-bit detached-panel mask in the primary `GTT_Prototype_01` save snapshot.
- `AGTTStructuralGameMode` extends the existing save/load loop without replacing gameplay systems: active Native Chaos mirrors are flushed before the base save, structural state is appended as save schema v5, and Native takeovers are safely cycled during load before exact body state is restored.
- `ApplyScriptedImpactDamage` exposes the same Native structural damage model used by physical impacts for deterministic mission/cinematic crashes. It still routes through `ApplyNativeImpactDamage`, including zone health, condition/tire loss, detachable debris and workshop surcharge math.
- Restored detached panel state now reconstructs physical debris proxies so a saved damaged vehicle does not silently become visually pristine on reload.
- Unified save consolidation no longer downgrades newer primary save schemas back to v4.

## Runtime evidence
- New `UGTTStructuralDamageEvidenceSubsystem` runs after the 0.0.92 spike-damage recovery proof and creates measurable left/front structural damage, non-zero cooling stress and at least one detached panel.
- The evidence route uses the real `SaveProgress`/`LoadProgress` path, deliberately clears live structural state after saving, then requires exact zone/cooling/panel-mask restoration from save schema v5.
- The same vehicle is sent through the real paid workshop/economy interaction. PASS requires a positive structural surcharge, restored body zones, zero cooling stress, zero detached-panel mask, and a post-repair save that remains pristine.
- `DEMO_SCENARIO.json` advances to `gtt.demo-scenario.v10` with 30 required proofs, adding `STRUCTURAL_PERSISTENCE` and `STRUCTURAL_REPAIR` while retaining all 28 previous core/spike/workshop checks.
- Win64 evidence defaults to 0.0.93 and extends the packaged runtime observation window to 105 seconds (`LaunchTimeoutSeconds 120`).

## Validation scope
- Project sanity validates the structural save schema, active game mode, Native persistence API, anti-stale round trip, paid surcharge recovery, evaluator hard gates and SWIR roadmap style lock.
- This milestone does **not** claim a successful UE 5.8 Win64 compile/package, packaged-EXE runtime smoke, or rendered visual acceptance. Those still require the configured self-hosted Unreal runner and visual review before any public demo release.
