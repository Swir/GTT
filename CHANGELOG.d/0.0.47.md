# GTT 0.0.47 — Native Fieldmaster Terrain & Heavy-Haul Integration

## Added
- Native Fieldmaster terrain response wired into existing authored `GTTMudZone` volumes.
- Native mud traction loss, rolling drag and tire-integrity wear that respect the existing tire-upgrade level.
- Native Fieldmaster impact-damage entry point for condition and severe-impact tire degradation.
- Direct Native Fieldmaster `rear_hitch` transform access gated by the accepted rig contract.
- Direct articulated farm-trailer attachment to the Native Fieldmaster skeletal mesh.
- Heavy-haul contract discovery and hitch routing for an active Native Fieldmaster takeover.
- Native tractor condition participation in heavy-haul condition-sensitive payout.

## Changed
- Hidden legacy Fieldmaster mirrors are ignored by heavy-haul vehicle discovery while Native takeover is active.
- Existing trailer break/re-hook, cargo stability and integrity logic now works with either legacy or Native Fieldmaster towing.
- Authored mud zones remain the single world-side source for off-road penalties instead of introducing Native-only terrain volumes.
