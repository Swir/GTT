# GTT 0.1.35 — Packaged Farm Cargo Emergency Patch Evidence

## Added

- Added `UGTTFarmCargoPatchEvidenceSubsystem`, an opt-in packaged-smoke route that drives the real Farm Cargo terminals, native Mulebox damage model, breakdown decision, player-authorized emergency patch, exact cargo authority, delivery payout/reputation and primary save paths.
- Added deterministic proof for the emergency-patch branch: native breakdown, patch eligibility, positive paid patch, exact `PersistentVehicleId` continuity, running cargo timer, non-improving cargo integrity, preserved body/detached-panel state, limp-home condition/tire/fuel floors and wrong-vehicle rejection after service.
- Added `evaluate_farm_cargo_patch_runtime.ps1`, producing `FARM_CARGO_PATCH_RUNTIME.json` with schema `gtt.farm-cargo-patch-runtime.v1` only when phase evidence, production recovery checkpoints, native patch markers and final completion values agree.
- Added a 110-scenario manual/runtime playtest matrix plus dedicated source-contract verifier and GitHub Actions sanity workflow.

## Changed

- Packaged runtime smoke now explicitly enables `-GTTFarmCargoPatchScenario` after the existing Farm Cargo tow evidence window.
- The main Win64 evidence window is extended to 276 seconds with a 300-second launch timeout so the patch route runs after earlier drivetrain, trailer, base cargo, save/load and tow scenarios instead of overlapping them.
- Demo technical evaluation advances to schema 10 and requires the emergency-patch manifest in addition to all existing Native Chaos, drivetrain, trailer and Farm Cargo evidence.
- Historical 0.1.33 source verification now enforces minimum runtime-window thresholds rather than freezing later evidence pipelines to the old exact 250/275-second values.
- GTT progress verification follows the current `SWIR-PROGRESS-SVG-PRO:v1` presentation rule: the protected roadmap markers, badges, numeric table, checklist and deterministic SVG remain authoritative while the retired character progress meter is removed and prevented from returning.

## Verification / release truth

- Roadmap completion remains **125/130 (96.2%)**. This source milestone does not close Native Chaos, authored-trailer, packaged Win64, full runner or visual acceptance blockers.
- Source-contract CI verifies wiring, anti-bypass rules, recovery checkpoints, exact-vehicle invariants, evaluator requirements and deterministic SVG presentation. It **does not prove** that Unreal Engine 5.8 compiled the new C++ or that a packaged Windows EXE executed the emergency-patch route.
- `FARM_CARGO_PATCH_RUNTIME.json` is authoritative only when produced from the exact packaged candidate on a qualifying Windows x64 + UE 5.8 runner.
- Public demo release remains blocked until all technical and visual gates pass on the exact candidate.
