# GTT 0.0.49 — Trailer Axle & Impact Physics

## Added
- Physical left/right trailer wheel bodies with real collision, per-wheel mass and independent rigid-body simulation.
- Breakable axle constraints that lock wheel translation/swing while leaving the rolling twist axis free.
- Trailer axle-health tracking through `HasIntactAxle()` plus wheel-loss consequences for trailer integrity and loaded cargo stability.
- Trailer-body `NotifyHit` damage routing with impact threshold, duplicate-contact cooldown and severe-impact cargo damage.

## Changed
- Heavy-haul trailer wheels are no longer presentation-only non-colliding components; road/terrain contact can now influence the articulated trailer physically.
- Losing one or both wheel constraints now materially worsens the existing heavy-haul risk/reward loop instead of leaving cargo integrity unaffected.
- Trailer reset recreates both axle constraints and clears wheel-loss state so repeatable work remains recoverable.
- Existing Native Fieldmaster `rear_hitch`, hitch break/re-hook, loaded mass and condition-sensitive payout remain the authoritative heavy-haul path.
