# GTT 0.1.8 — Dispatcher Relationships & Multi-Order Contract Desk

## Added
- `UGTTDispatcherRelationshipSubsystem`, a gameplay relationship layer for Feed Dispatcher, Hill Receiver and Wood Foreman. Relationship scores are derived from the already-persistent delivery record (CARGO/ROAD completions and failures, logistics reputation and clean streak), so existing schema-v8 saves gain deterministic relationships without a second reputation save or destructive migration.
- Four dispatcher relationship states: `NEW DRIVER`, `KNOWN`, `TRUSTED` and `PREFERRED`, with role-specific reactions to the player's actual delivery history.
- A shared transport-desk summary that presents the currently available CARGO choices alongside the ROAD courier opening state instead of treating the two logistics loops as unrelated systems.
- Relationship-backed Feed Dispatcher desk access. Manual CARGO reservations are limited to T1 for new drivers, T2 once dispatcher trust reaches the mid tier and T3 for preferred drivers, while still respecting the stricter existing global reputation, stock and destination-demand gates.
- Contract-board feedback for relationship-locked loads, including the current driver relationship, current desk-access tier and a direct instruction to run clean lower-tier work instead of presenting an apparently broken `UNAVAILABLE` state.
- `Scripts/verify_dispatcher_relationship_desk.py` and `Docs/PLAYTEST_0.1.8.md`, wired into Project sanity.

## Changed
- Feed Dispatcher world interaction is now `E DESK`: repeated interaction still cycles the authoritative 0.1.7 negotiated order, but skips tiers the current driver relationship has not earned yet. The accepted selection remains the same market-backed `CargoNegotiatedOrderTier`, so no duplicate mission state was introduced.
- Hill Receiver and Wood Foreman status interactions now react to their own derived relationship scores while continuing to report live demand, backlog, commodity and ROAD/CARGO supply information.
- Farm CARGO acceptance now checks the Feed Dispatcher relationship in addition to the existing fleet readiness, work schedule, stock/demand, wanted/game-warden and reputation constraints. Vehicle preparation is still allowed before trust is sufficient, so the relationship gate does not waste a player's service/dispatch planning.
- ROAD boards now display the same shared transport-desk summary, connecting Rattleback courier work to the same rural logistics desk without changing the proven ROAD payout/schedule rules.
- SaveVersion remains 8. Relationships intentionally come from the already-persistent authoritative logistics history, while the same-day negotiated CARGO selection continues to use the existing additive 0.1.7 fields.
- Roadmap remains exactly **125/130 (96.2%)**. This gameplay milestone does not close any authored Native Chaos, trailer or real Win64 package/runtime gate.
