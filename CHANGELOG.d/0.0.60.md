# 0.0.60 — Native Terrain-Load & Hill Control

- Added a dedicated low-speed Native Fieldmaster terrain/load controller that complements the existing higher-speed stability subsystem instead of duplicating it.
- Authored mud severity, terrain grip, trailer tow load, road grade and front/rear wheel-clearance evidence now combine into a live launch-grip estimate.
- Heavy trailer tongue load and front-axle unloading reduce usable hill-start throttle authority, making loaded muddy climbs require smoother inputs.
- Added rollback detection on meaningful grades: sustained backwards motion while the driver requests throttle now cuts drive and applies a proportional hold brake before the tractor can gather dangerous reverse speed.
- Added `NATIVE_TERRAIN_LOAD_EVIDENCE` runtime telemetry covering grade, mud, grip, tow load, axle clearances, rear-load bias, launch grip, throttle limit and rollback-control state.
- Added dedicated playtest and Project sanity coverage while keeping the roadmap at 125/130 until genuine authored Native Chaos and Win64 runtime acceptance exists.

## Limitations / next
- Repository CI still verifies source contracts only; it does not prove Unreal Engine 5.8 Win64 compilation, packaged runtime behavior or visual quality.
- The next acceptance step should use an Unreal-capable Windows runner to capture wheel/suspension runtime evidence and validate these controls against the authored Physics Asset and real Chaos wheel setup.
