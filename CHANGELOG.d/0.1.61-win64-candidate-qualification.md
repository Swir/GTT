# GTT 0.1.61 — Win64 Candidate Qualification & Authored Trailer Import

## Added
- Added an exact-candidate authored-trailer import gate to the canonical UE 5.8 Win64 evidence workflow, before packaging.
- Added `AUTHORED_TRAILER_IMPORT.json`, bound to the exact commit SHA and project version, and carried it through the technical-candidate artifact and reviewed-release gate.
- Added a deterministic Linux/source verifier plus dedicated CI that locks package/import/runtime/visual/release gate ordering.
- Added a real `ProjectVersion=0.1.61` source of truth so manually dispatched package/release jobs cannot silently publish a stale or mistyped candidate label.
- Added a dedicated acceptance/playtest contract covering positive and fail-closed Windows candidate cases.

## Changed
- Removed stale hard-coded `0.1.52` package and `0.1.20` release defaults; candidate version must now be explicit and match the exact checked-out project metadata.
- The package lane now proves the final `SK_GTT_FarmTrailer.uasset` exists after UE import before `package_windows.ps1` may run.
- The reviewed Demo Release lane now rejects candidates without exact-SHA/version authored-trailer import evidence and no longer claims a brittle fixed gameplay-step count in release notes.
