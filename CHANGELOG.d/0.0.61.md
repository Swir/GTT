# 0.0.61 — Native Per-Wheel Load & Cross-Axle Control

- Reworked the Native Fieldmaster terrain/load controller from axle-average evidence to four independent wheel probes using the canonical Fieldmaster wheel bones.
- Added normalized per-wheel load estimates, grounded-wheel count, front/rear axle load factors, left/right side imbalance and front/rear cross-axle imbalance.
- Combined authored terrain grip, tire integrity/upgrades, trailer tongue load and per-wheel load evidence into separate front- and rear-axle grip estimates.
- Added sustained cross-axle risk control at low/medium speeds: progressive throttle limiting and light braking reduce wheelspin/instability when one side unloads or wheel contact is lost; severe cases temporarily suppress steering.
- Kept hill-start/rollback control and heavy-haul behavior integrated in the same controller so interventions compose instead of creating a disconnected vehicle state.
- Added `NATIVE_WHEEL_LOAD_EVIDENCE` telemetry with four clearances, normalized loads, contact count, axle grip, split imbalance, intervention risk and brake authority.
- Added dedicated playtest and Project sanity coverage while preserving the roadmap at 125/130 until authored Native Chaos wheel/suspension runtime and Win64 acceptance are genuinely verified.

## Limitations / next
- Per-wheel load is currently inferred from authored wheel-bone clearance/contact evidence; repository CI cannot prove real Chaos suspension compression or tire force values without an Unreal-capable runner.
- The next milestone should validate these proxies against the actual Chaos wheel setup and replace/augment them with runtime wheel-state evidence where UE 5.8 exposes stable telemetry.
