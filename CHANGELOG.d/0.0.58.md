# 0.0.58 — Native Traction & Slip Control

- Added Native Fieldmaster traction-risk evaluation driven by lateral chassis slip, four-wheel contact evidence, front/rear load transfer, side loading, tire integrity and tire upgrade level.
- Added separate front- and rear-traction estimates so heavy trailer tongue load and axle unloading affect the tractor before the stronger rollover/fishtail safety layer is reached.
- Added a short sustained-loss grace period and progressive traction control: requested throttle is reduced and light braking can be applied during moderate persistent slip; severe combined traction loss escalates into the existing full stability intervention.
- Connected the controller to the real requested Native Fieldmaster throttle instead of inventing a parallel input/state model.
- Expanded `NATIVE_STABILITY_EVIDENCE` with `traction_risk`, `slip_deg`, `front_traction`, `rear_traction`, `traction_loss_s`, `traction_control`, `throttle_limit` and tire-integrity evidence.
- Added 0.0.58 runtime playtest coverage and Project sanity verification.
- Roadmap remains 125/130: dedicated authored Native Chaos drivetrain/suspension/wheel setup and Win64 runtime acceptance are still not claimed without real UE 5.8 evidence.
