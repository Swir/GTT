# GTT 0.0.84 — Native Motion & Pursuit Runtime Proof

## Added
- Packaged demo scenario now requires live four-wheel Chaos state, at least two ground contacts, valid suspension samples and measurable planar motion for Fieldmaster, Rattleback 82 and Mulebox 1200.
- Police evidence now requires an actually spawned foot response and an active pursuit vehicle instead of accepting the mere presence of the police director.
- Deterministic smoke-only crime escalation targets wanted level 3 (80 heat), the configured pursuit-vehicle escalation threshold.
- `DEMO_SCENARIO.json` schema v3 hard-gates all 17 gameplay/runtime milestones and remains SHA-bound through the existing evidence chain.

## Changed
- Win64 evidence workflow advances to 0.0.84 and names the native-motion/pursuit route explicitly.
- Scenario timeout expands to 45 seconds and SAVE waits until 24 seconds, allowing real response/motion evidence to emerge before persistence is tested.
- Normal gameplay remains unaffected because all deterministic actions are still opt-in behind `-GTTDemoSmokeScenario`.

## Limitations / Next
- Source-level sanity can verify the evidence contract, not execute UE 5.8 physics. A self-hosted Windows x64 Unreal 5.8 runner is still required for package/runtime proof.
- No demo Release is allowed until packaged Win64 smoke, this 17-step route, fleet Native Chaos smoke-ready evidence and rendered visual acceptance all pass.
