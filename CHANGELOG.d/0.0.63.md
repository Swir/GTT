# 0.0.63 — Native Chaos Wheel-State Runtime Control

## Added

- Direct runtime sampling of all four Native Fieldmaster `FWheelStatus` records through `UChaosWheeledVehicleMovementComponent::GetWheelState()`.
- `NATIVE_CHAOS_WHEEL_STATE_EVIDENCE` telemetry with real Chaos contact, normalized suspension length, spring force, drive/brake torque, slip/skid flags and slip magnitude.
- A safe `TRACE_FALLBACK` path that keeps the existing authored four-point ground probes active whenever Chaos does not provide four valid wheel states.

## Changed

- Native stability/contact logic now prefers Chaos-reported wheel contact over proxy traces when the four canonical states are valid.
- Runtime slipping/skidding and missing per-wheel contact now feed the existing traction-risk calculation and can reduce front/rear available grip, throttle and ultimately steering through the established stability controller.
- Existing heavy-haul sway, load-transfer, tire integrity, tuning, mud, condition, fuel and save/load state remain authoritative and are combined with the new runtime evidence rather than duplicated.

## Verification boundary

Project sanity statically verifies the integration contract and preserves all five runtime-only roadmap tasks as open. This milestone is **not** proof of a successful Unreal Engine 5.8 compile/package or packaged Win64 runtime. The dedicated Native Chaos roadmap checkboxes remain open until that evidence exists.
