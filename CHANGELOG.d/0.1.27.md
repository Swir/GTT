# GTT 0.1.27 — Demo Vertical Slice Integration

## Added

- Added a presentation-only `AGTTFarmRouteBeacon` that follows the authoritative farm-cargo stage and points to the real Feed Depot, Hill Farm and North Wood Yard terminals.
- Added `UGTTFarmRouteGuidanceSubsystem`, which owns exactly one route beacon per game world and avoids per-interaction marker spawning.
- Route guidance now displays compact destination distance plus the existing delivery timer and cargo-integrity state during loaded legs.
- Added ground projection against `WorldStatic`, collision-free presentation and player-facing text so guidance remains readable without becoming another gameplay authority.

## Changed

- Hill Farm and North Wood Yard legal cargo handoffs now reject a controlled cargo vehicle travelling above **3.0 km/h**, preventing drive-by completion while leaving the existing delivery timer running.
- Handoff interaction text now communicates that the vehicle must be stopped before cargo is signed over.
- The 0.1.27 source contract explicitly verifies the full existing authority chain from unified contract-board acceptance through stock reservation, physical cargo load factor, police-blocked handoff, cash payout, logistics reputation and save persistence.

## Verification

- Added `Scripts/verify_demo_vertical_slice.py` and a dedicated GitHub Actions workflow that also reruns contract-board preparation and the previous 0.1.26 ranger world-marker regression gate.
- Added `Docs/PLAYTEST_0.1.27.md` with manual gameplay, presentation and future packaged-runtime scenarios.
- Roadmap completion remains **125/130 (96.2%)**. No Native Chaos, authored-trailer or Win64 runtime blocker is closed by this source-only milestone.
- This milestone does **not** claim a UE 5.8 Win64 compile, packaged-EXE smoke test, rendered visual acceptance or public demo release.
