# GTT 0.1.57 — Fieldmaster native link/runtime hardening

## Native Chaos blocker fix
- Restored the six `AGTTFieldmasterNativePawn` runtime definitions that were declared in the native pawn header but absent from the compiled implementation: hit notification, impact damage, native mud response, mud severity, terrain grip, and rear hitch transform.
- `NotifyHit` now forwards to `Super`, derives a bounded impact-speed estimate from rigid-body impulse/vehicle speed, applies a cooldown, and routes damage through the native 0..1 migration state.
- Native mud volumes now have a concrete Chaos-side implementation: horizontal drag mirrors the legacy mud contract, tire wear respects tire upgrades, and the movement component receives a short-lived terrain grip reduction.
- The authored Fieldmaster hitch socket now has a concrete runtime transform query for trailer integration.

## Verification
- Added a deterministic source/link-contract verifier that fails if any declared Fieldmaster runtime method is missing or duplicated.
- Added a dedicated GitHub Actions sanity workflow that runs on relevant native-vehicle changes.
- This closes a source/link blocker only. It does **not** claim Unreal Engine 5.8 Win64 compile/cook/package, runtime acceptance, authored trailer-wheel acceptance, or demo readiness.
