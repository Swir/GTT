# 0.0.59 — Native Terrain Grip & Collision Consequences

- Deepened the existing Native Fieldmaster environment path instead of creating a parallel terrain model: authored `GTTMudZone` volumes now expose short-lived mud severity and terrain-grip state from the same takeover pawn.
- Native mud response now combines terrain severity, current tire health and tire upgrades into usable throttle authority, while physical horizontal drag scales with mud severity.
- Mud wear remains on the authoritative migration `TireIntegrity`, so the consequence persists through the existing legacy mirror/save path and feeds the 0.0.58 front/rear traction-risk controller.
- Tire upgrades reduce wear and improve grip modestly but cannot eliminate mud consequences.
- Native collision damage retains the existing cooldown and condition/tire consequences, and now emits `NATIVE_IMPACT_DAMAGE` evidence with real condition/tire deltas when a hit mutates gameplay state.
- Added `NATIVE_TERRAIN_RESPONSE` evidence, dedicated 0.0.59 playtest coverage and a Project sanity check that proves the terrain/collision implementation remains connected to the authored mud volumes and shared traction state.
- Roadmap remains 125/130 (96.2%): this strengthens the source/runtime contract, but no Native Chaos or Win64 checkbox is closed without a genuine UE 5.8 packaged-runtime acceptance run.
