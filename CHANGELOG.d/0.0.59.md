# 0.0.59 — Native Terrain & Collision Contract Repair

- Repaired a Native Fieldmaster source contract gap: `ApplyNativeMudResponse`, `ApplyNativeImpactDamage` and the declared `NotifyHit` override now have concrete implementations instead of remaining declaration-only compile hazards.
- Native takeover now consumes the same authored `GTTMudZone` volumes as the legacy tractor with progressive throttle loss, physical horizontal drag and tire wear tied to real speed, mud severity and existing tire-upgrade state.
- Mud tire wear mutates the authoritative migration `TireIntegrity`, so damage persists through the existing legacy mirror/save path and directly feeds the 0.0.58 front/rear traction-risk controller.
- Added short-lived Native mud severity / terrain-grip queries for runtime evidence and future suspension/traction integration without creating a second persistent terrain model.
- Native collision response now converts sufficiently hard chassis hits into condition damage, adds tire damage for severe impacts, applies a per-impact cooldown and forces braking if condition reaches zero.
- Added `NATIVE_TERRAIN_RESPONSE` and `NATIVE_IMPACT_DAMAGE` evidence plus dedicated 0.0.59 playtest and Project sanity coverage.
- Roadmap remains 125/130 (96.2%): this repairs and strengthens the source/runtime contract, but no Native Chaos or Win64 checkbox is closed without a genuine UE 5.8 packaged-runtime acceptance run.

## Limitations / next

- The next large milestone should consume Native terrain grip directly in authored Chaos wheel/suspension acceptance and capture real wheel-load/contact evidence on an Unreal-capable Windows runner.
