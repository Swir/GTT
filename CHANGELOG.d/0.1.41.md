## GTT 0.1.41 — Garage / Workshop Recovery Integration

### Added
- Transactional paid native-road workshop service on the existing `AGTTServiceTerminal`; no parallel workshop subsystem.
- Blueprint-friendly repair/fuel quote APIs and `PurchaseNativeRoadWorkshopService` for exact owned native vehicles.
- Post-service exact `PersistentVehicleId`, cargo-load and full-restoration verification with rollback + exact refund on failure.
- Wanted, ownership and physical service-radius guards plus explicit persistence-mirror flush and existing GameMode save on successful service.
- 68-scenario playtest and dedicated CI that also re-runs the existing garage fleet and roadside recovery contracts.

### Changed
- Roadside tow now has a complete downstream gameplay loop: transport stays damage-preserving and `serviced=NO`, then normal workshop `E / Interact` performs the separately-priced repair/refuel transaction.
- Fuel-only native visits retain per-litre billing but now verify exact identity/cargo continuity and roll back/refund if the mutation cannot be proven.
- Native road workshop prompts include the exact persistent vehicle ID and distinguish fuel-only from full-service quotes.
- Farm Cargo authority is not modified: service preserves the same vehicle/cargo load and does not own timer, integrity, payout or completion.

### Verification boundary
- Roadmap stays 125/130 (96.2%). This source milestone does not claim Native Chaos runtime acceptance, a UE 5.8 Win64 package, packaged EXE smoke or demo visual acceptance.
