# GTT 0.1.45 — Persistent Workshop Repair Queue & Deferred Economy

## Added
- Added `UGTTWorkshopRepairQueueSubsystem`, a persistent one-reservation queue for ordinary damaged/mobile Native road vehicles while the workshop is closed.
- Garage-office after-hours interaction can reserve the nearest eligible owned Native road vehicle instead of merely reporting that service is unavailable.
- Reservations pin the exact `PersistentVehicleId`, request-time repair quote, request day/time and deterministic next-opening day/time. The player is **not charged when booking**.
- Added `GTT_WorkshopQueue_01` transactional SaveGame sidecar (`UGTTWorkshopQueueSaveGame`) so the exact reservation survives save/load without becoming a second cash or vehicle authority.
- Added queue status for garage UI: `QUEUED`/`READY`, exact target ID, locked quote, next opening and live game-hours ETA.
- At/after opening the queue executes only when that exact owned Native road vehicle is physically parked by a real workshop terminal. The existing `ApplyNativeWorkshopService()` mutation and normal primary `SaveProgress()` remain authoritative.
- Insufficient cash leaves the reservation intact and unpaid. A failed vehicle mutation refunds the exact locked quote before clearing the reservation.
- Active Farm Cargo can queue only its already-bound exact vehicle; the queue never transfers cargo authority, reserves stock, pays revenue or changes cargo timing/integrity.

## Safety / economy rules
- A hard `TOW`/`IMMOBILE` WORKSHOP HOLD never enters the deferred queue. If an already-queued vehicle later becomes a hard hold, the reservation is discarded without charge so the established immediate emergency-recovery lane remains authoritative.
- An impounded target, conflicting Farm Cargo identity, ambiguous duplicate persistent ID or invalid saved reservation fails closed without a debit.
- Booking does not call `SpendCash`, repair/refuel APIs or primary-save progression. Debit happens once, immediately before successful queued workshop execution.
- Queue persistence is intentionally separate from the primary save so replay/cancellation cannot rewrite unrelated campaign, fleet or cargo fields.

## Changed
- `GTTWorkshopHoursPolicy` now exposes deterministic next-opening helpers shared by queue scheduling and UI instead of duplicating 06:30 rollover math.
- Garage office text now surfaces pending queue state and clearly distinguishes deferred ordinary repairs from the +35% after-hours emergency WORKSHOP HOLD path.
