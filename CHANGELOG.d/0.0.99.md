# GTT 0.0.99 — Persistent Fleet Dispatch & Job Fit

## Added
- Persistent garage dispatch selection for the owned fleet. A successful numbered-bay dispatch now marks that vehicle as the player's preferred active garage vehicle and stores the choice in save schema v6.
- Garage fleet roles: `TRACTOR`, `ROAD`, `CARGO`, and `UTILITY`, with deterministic role mapping for Rusty Fieldmaster 60, Rattleback 82, and Mulebox 1200.
- Job-aware garage guidance. Legal farm cargo contracts query the live garage fleet and tell the player whether the Mulebox cargo vehicle is already the active dispatch choice or which bay should be dispatched before the run.
- Backward-compatible migration: pre-v6 saves automatically fall back to the first valid owned fleet vehicle rather than retaining an invalid or missing preferred ID.
- `PLAYTEST_0.0.99.md` and `verify_fleet_dispatch_selection.py` covering dispatch persistence, role classification, job fit, economy locks, save migration, and roadmap style-lock integrity.

## Changed
- Garage bay recall is now a full dispatch action: it still costs $15, still obeys police/game-warden locks, still preserves damage/fuel/tuning, and now atomically commits the selected vehicle before `SaveProgress()`.
- Garage office and bay presentation identify the active vehicle and each vehicle's gameplay role instead of exposing only raw service state.
- Save schema advances from v5 to v6 without changing the v5 structural-damage compatibility threshold, so older structural records continue to restore correctly.
- Existing structural persistence sanity checks were updated to verify that v5 damage compatibility remains intact under the newer v6 save schema.

## Verification / limitations
- Project sanity receives a dedicated 0.0.99 fleet-dispatch gate and retains the locked SWIR roadmap dashboard. Roadmap remains exactly 125/130 (96.2%); no Unreal build/art checkbox is claimed by this source-level milestone.
- This update does not claim a verified UE 5.8 Win64 compile/package, packaged EXE runtime smoke, or rendered visual acceptance. Those remain mandatory before any public demo Release.
