# GTT 0.0.87 — Roadblock Spike Consequences

## Added
- Roadblock spike strips now expose runtime consequence evidence: impacted vehicle ID, before/after tire integrity and accepted hit count.
- Spike impacts emit `ROADBLOCK_SPIKE_CONSEQUENCE` telemetry with tier, tire delta, body damage and vehicle speed.
- Per-vehicle repeat-hit cooldown prevents one physical contact from applying uncontrolled damage multiple times in the same collision burst.

## Gameplay impact
- Breaking through a police roadblock continues to consume the shared tire/body damage model, but the consequence is now deterministic, measurable and suitable for packaged runtime proof.
- Tier-2 roadblocks remain more punishing than tier-1 while preserving repair/tuning/economy integration through `AGTTVehicleBase`.

## Limitations / next
- This milestone strengthens the real roadblock consequence path for the legacy/shared vehicle damage model. Native Chaos road-vehicle spike parity is the next migration target.
- Source sanity is not a substitute for a packaged UE 5.8 Win64 collision run or rendered visual acceptance.
