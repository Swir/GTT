# 0.0.55 — Native Stability & Contact Control

## Added
- `UGTTNativeStabilitySubsystem` for active Native Fieldmaster takeover.
- Four-wheel contact-aware stability risk using the canonical authored wheel-bone contract.
- Sustained low-contact detection with throttle cut and proportional brake intervention at road speed.
- Severe roll/pitch and one-wheel-contact protection that also neutralizes steering during rollover-risk states.
- Tire-upgrade-aware intervention strength using the existing shared migration snapshot.
- Periodic `NATIVE_STABILITY_EVIDENCE` runtime telemetry.
- `PLAYTEST_0.0.55.md` and `verify_native_stability.py` Project sanity coverage.

## Changed
- Native Fieldmaster handling now reacts to loss of wheel support and dangerous body attitude instead of only limiting top speed from damage/tuning state.
- Stability control consumes the same native takeover, wheel rig and persistent tire-upgrade state already used by the rest of the vehicle loop; no duplicate vehicle state was introduced.

## Limitations / Next
- Repository checks verify source wiring only; no UE 5.8 Win64 package/runtime was available in this iteration.
- Ground traces are gameplay-facing wheel-support evidence, not a claim that final Chaos suspension forces or tire contacts were runtime-approved.
- Roadmap remains 125/130 until authored Native Chaos suspension/drivetrain handling and Win64 package/runtime evidence are actually verified.
