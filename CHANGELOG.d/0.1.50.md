# GTT 0.1.50 — Workshop Job Board & Safe Appointment Control

## Added
- Physical `AGTTWorkshopJobBoardTerminal` integrated beside the existing garage/workshop loop, showing all authoritative multi-vehicle workshop appointments with exact vehicle ID, locked quote, lifecycle state and relevant ETA.
- Lifecycle-focused board triage (`SCHEDULED`, `CHECK-IN`, `WORKING`, `PAYMENT`) that reads the existing queue instead of duplicating service state.
- Safe exact-ID cancellation for waiting/ready appointments using a two-step six-second confirmation guard.
- Dedicated 48-case playtest matrix and source-contract verifier/workflow.

## Changed
- The garage now spawns one fallback job board only when an authored/nearby board is not already present and points players to it whenever workshop appointments exist.
- Appointment cancellation remains no-charge and uses the existing queue authority; the board deliberately owns no cash, repair/refuel or service-timer mutation.
- Roadmap progress remains 125/130 (96.2%): this player-facing gameplay/UX milestone does not close Native Chaos, authored trailer or Win64 runtime/visual acceptance gates.

## Verification / limitations
- Source verifier checks exact-ID two-step cancellation, garage spawn integration, presentation-only board authority and unchanged roadmap mathematics.
- Unreal Engine 5.8 Win64 compile/package/runtime smoke and rendered visual acceptance are still required before any public demo Release.
