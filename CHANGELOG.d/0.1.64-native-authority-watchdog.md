## GTT 0.1.64 — Native Chaos Authority Watchdog

- Added a fail-closed Native Chaos authority watchdog to the live Fieldmaster runtime telemetry path. Healthy takeover now continuously requires the dedicated Fieldmaster Chaos movement class, active movement, PhysicsAsset, visible/collidable native pawn and a hidden/collision-off/tick-off legacy mirror.
- Any split-authority invariant failure emits `NATIVE_FIELDMASTER_AUTHORITY_FAULT` with a stable reason code and immediately routes through the existing `DeactivateLegacyTakeover()` path to `RESTORE_LEGACY`, preventing a duplicated/ghost driving authority from remaining live.
- Healthy runtime telemetry now records `authority=NATIVE_CHAOS`, `takeover_integrity=PASS`, the exact movement class, quiescent legacy state, native collision and PhysicsAsset evidence alongside the existing wheel/contact/suspension/drivetrain telemetry.
- Added `evaluate_native_authority_runtime.ps1`, which binds packaged authority evidence to Win64 build metadata, exact candidate SHA and PASS runtime smoke, requires at least two healthy samples and rejects any authority fault before producing `NATIVE_AUTHORITY_RUNTIME.json`.
- Added deterministic source/integration verification, regression coverage and a fault-injection playtest contract preserving 0.1.59 heavy-haul, 0.1.62 hill-haul and 0.1.63 trailer-brake thermal behavior.
- This source/infrastructure milestone **does not close** any of the five remaining Native Chaos, authored-trailer or Win64 runtime/visual roadmap gates. Real packaged UE 5.8 evidence is still required.
