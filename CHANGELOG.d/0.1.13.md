# GTT 0.1.13 — Dedicated Native Chaos Tractor Movement & Demo Gate Hardening

## Added

- Added `UGTTFieldmasterChaosMovementComponent`, a Fieldmaster-specific subclass of `UChaosWheeledVehicleMovementComponent` that owns the canonical four-wheel Chaos setup and tractor powertrain validation.
- Added one native drive-authority path that composes requested throttle/steering with shared fuel, vehicle condition, tire integrity and terrain grip before those commands reach Chaos Vehicles.
- Added explicit stopped/failsafe behavior for invalid native configuration, empty fuel, broken condition, vehicle exit, takeover deactivation and garage recall.
- Added `PLAYTEST_0.1.13.md` and a dedicated source acceptance verifier for the new movement architecture.

## Changed

- `AGTTFieldmasterNativePawn` now replaces `AWheeledVehiclePawn`'s default movement subobject with the dedicated Fieldmaster movement class through the supported `FObjectInitializer::SetDefaultSubobjectClass` path.
- Native throttle/steering handlers now store driver intent and refresh the dedicated movement authority instead of issuing raw Chaos commands directly from the pawn.
- Native acceptance now requires the dedicated movement component, canonical wheel/powertrain validation and a Physics Asset while preserving the legacy tractor as the persistence/fallback mirror.
- The project sanity suite now verifies this movement ownership explicitly rather than treating a generic `UChaosWheeledVehicleMovementComponent` cast as sufficient architecture.

## Verification boundary

- This milestone provides source-level architecture and regression verification only until a real Unreal Engine Windows compile/runtime environment executes the playtest.
- The roadmap remains **125/130 (96.2%)**. `Dedicated native Chaos wheeled tractor movement`, `Dedicated native Chaos drivetrain/suspension/wheel setup`, the Win64 compile/package smoke test, authored trailer assets and the Win64 CI/build runner remain open until their real acceptance evidence exists.
- No Windows demo release is authorized by source sanity alone.
