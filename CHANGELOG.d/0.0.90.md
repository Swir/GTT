# GTT 0.0.90 — Deterministic Native Roadblock Crossing

## Added
- Packaged demo scenario now turns an active wanted-4 roadblock into a deterministic physical Native Chaos crossing instead of waiting for an accidental spike contact.
- The scenario selects a live Rattleback 82 or Mulebox 1200, stages it behind the active spike strip, aligns it with the strip and drives it through using the real Chaos movement component.
- Runtime evidence records wheel-risk before/after the strike and requires both tire degradation and increased wheel-risk before the new handling-consequence step can pass.
- `DEMO_SCENARIO.json` advances to schema v7 with physical-crossing and handling-risk evidence.

## Gameplay / release impact
The release gate now proves a causal chain inside the packaged sandbox: wanted escalation -> roadblock -> Native vehicle physically crosses the spike strip -> shared tire durability drops -> Native wheel-risk rises. This closes the gap where 0.0.89 required a real consequence but did not actively guarantee that the deterministic route would reach the strip.

## Verification boundary
The route still requires an Unreal-capable Win64 runner to prove the physical contact and resulting Chaos runtime state. Source sanity validates the deterministic route contract only; it does not claim a packaged EXE passed.
