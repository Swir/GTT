## GTT 0.1.62 — Fieldmaster Hill-Haul Control

- Native Rusty Fieldmaster 60 propulsion now composes tire/terrain traction with existing condition and trailer-load authority, so mud and damaged tires reduce effective throttle as well as steering.
- Added loaded low-speed hill hold for meaningful attached trailer loads on >=4 degree grades; deliberate throttle input releases the hold immediately.
- Added bounded throttle-off downhill tow braking that grows with grade/speed and trailer load while preserving the shared drivetrain/axle composer as the final stricter brake authority.
- Preserved the 0.1.59 heavy-haul ceilings: full trailer load remains 70% maximum throttle and 88% steering on firm ground; 0.1.62 can only reduce authority further.
- Added Blueprint-readable hill-haul telemetry for terrain throttle authority, travel grade, applied hill-haul brake and active hill/downhill control states.
- Added deterministic source/math verification, regression checks and a dedicated playtest contract. Packaged UE 5.8 / Win64 runtime acceptance remains an external release gate and is not claimed by this milestone.
