# GTT 0.1.16 — Direction-safe automatic drivetrain authority

- Removed per-tick `SetTargetGear(+/-1)` from the dedicated Fieldmaster movement command path. Fieldmaster condition/terrain scaling still owns throttle, steering and brake preparation, while `UGTTNativeDriveDynamicsSubsystem` is now the single final direction/gear authority shared by Fieldmaster, Rattleback and Mulebox.
- Fixed an automatic-transmission conflict where repeatedly requesting forward gear `1` could prevent Chaos from retaining its own `1 -> 2 -> 3...` decisions. The authority now writes a target gear only when a direction change is committed or Chaos is neutral/opposite to the stable direction.
- Hardened forward/reverse changes: above the existing 3.5 km/h release threshold the current gear is left intact, throttle is cut, steering is bounded and braking is applied. The reverse/forward target is written only after speed falls into the safe shift window.
- Added automatic gearbox evidence counters and log markers (`NATIVE_AUTOMATIC_GEAR_SHIFT`, `NATIVE_AUTOMATIC_GEARBOX_EVIDENCE`) without weakening the older drivetrain telemetry contracts.
- Extended `NATIVE_FIELDMASTER_RUNTIME_TELEMETRY` with signed longitudinal speed, automatic-gear state and configured forward-gear count. The Win64 evaluator now requires automatic gears to be live in packaged telemetry, records the highest forward gear observed, and rejects any logged direction-shift commit above the safe release window.
- Added a dedicated 0.1.16 regression gate plus playtest coverage for forward automatic shifting, high-speed direction interlock, safe shift commit, damaged/low-grip operation, trailer load and packaged evidence.
- This source/CI milestone does **not** claim Unreal Engine 5.8 Win64 compile/package, packaged EXE runtime, rendered visual acceptance, or closure of the five remaining hardware/runtime Roadmap gates. `Docs/ROADMAP.md` intentionally remains 125/130 (96.2%).
