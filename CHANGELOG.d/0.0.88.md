# GTT 0.0.88 — Native Chaos Spike-Strip Parity

## Added
- Police roadblock spike strips now damage active Native Chaos road vehicles, not only their legacy mirrors.
- Native Rattleback 82 and Mulebox 1200 consume the same tier-scaled tire/condition consequence used by the existing roadblock loop.
- Spike damage immediately syncs back into the persistent legacy/save mirror, preserving workshop, garage and save/load continuity.
- Roadblock telemetry now records whether the consequence was applied through the `LEGACY` or `NATIVE_CHAOS` path.
- Project sanity now hard-gates Native spike-strip parity.

## Gameplay impact
A player escaping in a Native Chaos old car or van can no longer bypass police tire consequences by virtue of the runtime takeover. Crossing a spike strip reduces tire integrity, feeds the existing Native wheel-risk/grip/steering model, and carries the damage into the workshop/save loop.

## Verification boundary
Source/contract sanity can verify the integration contract. A real Unreal Engine 5.8 Win64 package and runtime roadblock crossing are still required before claiming packaged-EXE verification or publishing the first demo.
