# GTT 0.0.97 — Garage Fleet Operations & Service UX

## Added
- Authoritative `UGTTGarageFleetSubsystem` with deterministic fleet slots and compact snapshots for condition, fuel, tires, body health, tuning, occupancy and service state.
- Native road-vehicle fleet authority: active Rattleback 82 / Mulebox 1200 Chaos pawns override stale hidden compatibility-mirror values and reuse the existing breakdown decision subsystem for real repair/tow estimates.
- Garage office fleet dashboard showing READY / LIMP / TOW / IMMOBILE states and exact service guidance for up to four owned vehicles.
- Dedicated 0.0.97 playtest and repository verifier wired into Project sanity.

## Changed
- Numbered garage bay labels now show live C/F/T/B condition and service state instead of only a vehicle name.
- Garage recall now supports active Native road-vehicle takeovers directly, clears residual vehicle motion, synchronizes the persistence mirror and saves the successful operation.
- Recall explicitly preserves damage, fuel and tuning; it remains a paid transport convenience and never becomes a free workshop repair.
- Garage registration now targets nearby unowned vehicles, so an already-owned vehicle at the office does not hide the fleet-inspection interaction.
- Workshop interaction text now exposes the real Native road-vehicle repair/refuel estimate before the player spends cash.
