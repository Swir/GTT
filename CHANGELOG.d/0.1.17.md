# GTT 0.1.17 — Deterministic Native Gear/Reverse Runtime Scenario

- Added a dedicated late-running Native Fieldmaster drivetrain evidence subsystem. It starts after the existing 0–75 second deterministic demo controls, so the new automatic-gear/reverse exercise does not race the core smoke scenario.
- Added a real `forward-auto-reverse-forward` packaged route: initial forward selection is written once, Chaos must reach automatic gear 2+, the tractor is braked through a high-speed reverse interlock, reverse is committed only inside the 3.5 km/h release window, measurable reverse motion is required, and the same safe-stop rule is used before returning to forward motion.
- Added explicit runtime markers for `AUTOMATIC_UPSHIFT`, `REVERSE_INTERLOCK`, `REVERSE_COMMIT`, `REVERSE_MOTION`, `FORWARD_COMMIT`, `FORWARD_MOTION` and final scenario completion. The pass has a 122-second deadline so its evidence is emitted before the existing 125-second package-smoke minimum may end.
- Added `evaluate_drivetrain_scenario.ps1`, which creates `NATIVE_DRIVETRAIN_SCENARIO.json` (`gtt.native-drivetrain-scenario.v1`). Acceptance requires the same Win64 build SHA, passing runtime smoke, a passing Native Chaos runtime manifest, gear 2+ evidence, measurable reverse/forward travel and safe direction commits at no more than 3.75 km/h.
- Integrated the new evaluator into the self-hosted UE 5.8 Win64 evidence workflow after `NATIVE_CHAOS_RUNTIME.json`; a missing or failing deterministic drivetrain manifest now prevents the technical candidate artifact from completing. The manifest is retained in verified artifacts and failure diagnostics when available.
- Added a dedicated 0.1.17 source/contract sanity workflow plus Project sanity coverage and a 20-scenario runtime playtest. Existing 0.1.16 automatic-drivetrain, deterministic-demo and packaged Native Chaos telemetry checks remain regressions in the new gate.
- This milestone does **not** claim a verified UE 5.8 Win64 compile/package, packaged EXE runtime PASS, visual acceptance, or closure of any runtime/hardware Roadmap item. Until a qualifying Windows runner actually produces the new manifest from the packaged game, `Docs/ROADMAP.md` intentionally remains **125/130 (96.2%)**.
