## GTT 0.1.63 — Trailer Brake Thermal Control

- Sustained throttle-off downhill trailer braking now builds a bounded time-based brake heat state instead of providing identical trailer-assist authority indefinitely.
- Trailer-assist brake fade starts only after the verified heat threshold and degrades progressively to a conservative 55% floor; it never removes all downhill assistance.
- Leaving the downhill-brake condition cools the system and deterministically restores full trailer-assist authority.
- Thermal integration clamps frame delta to 100 ms so a transient hitch cannot instantly overheat or cool the system.
- Hill hold, idle/base braking and the shared drivetrain/axle authority are explicitly outside the fade path, while 0.1.59 heavy-haul throttle/steering caps and 0.1.62 terrain/hill-haul behavior remain intact.
- Added Blueprint-readable brake heat, brake authority, fade-active and cooling-active telemetry for HUD/debug/playtest integration.
- Added deterministic source/math verification, regression CI and a dedicated playtest contract. This source milestone does not claim packaged UE 5.8 / Win64 runtime acceptance and does not close any of the five remaining roadmap release gates.
