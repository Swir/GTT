# GTT 0.0.91 — Post-Spike Escape Dynamics

## Added
- The deterministic packaged scenario now continues driving the physically spiked Native Chaos road vehicle for at least three seconds instead of stopping as soon as tire damage is observed.
- Native road vehicles expose runtime throttle, steering and brake-assist limits as read-only gameplay telemetry so the release gate can measure actual control-authority consequences rather than infer them from tire health alone.
- Post-spike evidence applies sustained throttle plus alternating steering and requires live wheel motion after the roadblock strike.
- `DEMO_SCENARIO.json` advances to schema v8 and records throttle/steering limits before and after the spike strike plus the post-spike escape result.

## Gameplay / release impact
A roadblock strike now has to remain meaningful while the chase continues: tire integrity must fall, wheel risk must rise, at least one real control-authority limit must worsen, and the damaged Native vehicle must remain physically moving during a follow-up escape segment. This connects police spike strips to the existing Native Chaos handling model instead of treating damage telemetry as the end of the interaction.

## Verification boundary
Repository sanity can verify the source/evidence contract, but the new escape route still needs an Unreal Engine 5.8 Win64 package and packaged runtime execution to prove the physical behavior. No EXE or public demo is claimed by this milestone alone.
