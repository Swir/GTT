# GTT 0.1.60 — Authored Trailer Runtime Bridge

## Added
- Added a fail-closed runtime presentation subsystem for the canonical authored farm-trailer skeletal asset.
- Added strict runtime validation for the required `body`, `wheel_l`, `wheel_r` bones, all four final trailer sockets and an assigned PhysicsAsset before placeholder presentation can be replaced.
- Added authored wheel-bone driving from the existing physical `LeftWheel` / `RightWheel` bodies so suspension travel and wheel-loss motion remain tied to the authoritative trailer physics.
- Added source-contract verification, dedicated GitHub Actions coverage and a complete Unreal/PIE acceptance checklist.

## Preserved authority
The new subsystem owns presentation only. Existing `AGTTFarmTrailer` collision, hitch load, suspension, wheel constraints, damage, cargo integrity, roadside repair and economy authority remain unchanged. If the authored Unreal asset is unavailable or incomplete, the system keeps the proven placeholder visuals instead of partially activating.

## Release-gate truth
This materially advances the authored-trailer blocker but does not close it. The final UE 5.8 skeletal asset still needs real import, sockets/PhysicsAsset confirmation, same-SHA Win64 packaged runtime evidence and rendered visual acceptance. Roadmap truth remains 125/130 (96.2%).
