# GTT 0.1.60 — Authored Trailer Runtime Bridge

## Added
- Added a fail-closed runtime presentation subsystem for the canonical authored farm-trailer skeletal asset.
- Added strict runtime validation for the required `body`, `wheel_l`, `wheel_r` bones, all four final trailer sockets and an assigned PhysicsAsset before placeholder presentation can be replaced.
- Added authored wheel-bone driving from the existing physical `LeftWheel` / `RightWheel` bodies so suspension travel and wheel-loss motion remain tied to the authoritative trailer physics.
- Added passive packaged-runtime evidence emission matching the existing `evaluate_authored_trailer_runtime.ps1` schema: authored activation, wheel contact/clearance, axle tilt, hitch alignment, articulation, stability/jackknife state and a loaded Native Fieldmaster tow scenario.
- Added deterministic source verification that locks the telemetry thresholds to the authoritative 0.1.60 road-feedback constants and rejects any physics/economy authority inside the presentation/evidence bridge.
- Added dedicated GitHub Actions coverage and an expanded Unreal/PIE acceptance checklist.

## Runtime evidence gate
The evidence path is observational only. A scenario PASS marker requires real authored takeover, loaded Native Fieldmaster attachment, at least 900 cm travel, at least 4 km/h peak speed, eight dual-contact/safe-hitch samples and a controlled stop. Hitch error above 110 cm emits an explicit failure diagnostic. The packaged evaluator still requires Win64 build metadata, packaged smoke PASS, Native Chaos/drivetrain PASS evidence and matching commit SHA.

## Preserved authority
The subsystem owns presentation and telemetry only. Existing `AGTTFarmTrailer` collision, hitch load, suspension, wheel constraints, damage, cargo integrity, roadside repair and economy authority remain unchanged. If the authored Unreal asset is unavailable or incomplete, the system keeps the proven placeholder visuals instead of partially activating.

## Release-gate truth
This materially advances the authored-trailer blocker but does not close it. The final UE 5.8 skeletal asset still needs real import, sockets/PhysicsAsset confirmation, same-SHA Win64 packaged runtime evidence and rendered visual acceptance. Roadmap truth remains 125/130 (96.2%).
