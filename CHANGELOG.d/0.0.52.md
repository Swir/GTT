# 0.0.52 — Native Chaos Runtime Guard & Evidence

## Added
- Automatic `UGTTNativeChaosRuntimeGuardSubsystem` for active Native Fieldmaster takeovers.
- Runtime-health contract covering native readiness, active Chaos movement, Physics Asset presence and enabled collision.
- Periodic `NATIVE_CHAOS_EVIDENCE` log records with live takeover/readiness, movement, physics, collision, occupancy, speed, condition and fuel state.
- `PLAYTEST_0.0.52.md` and `verify_native_chaos_runtime_guard.py` coverage wired into Project sanity.

## Changed
- A Native Fieldmaster takeover that remains runtime-unhealthy beyond the grace window now automatically returns through the existing legacy fallback path instead of leaving the player in a broken native pawn.
- Runtime evidence is explicitly diagnostic only; it does not close Native Chaos or Win64 roadmap work without real UE 5.8 execution.

## Limitations / Next
- No packaged Win64 Unreal build or rendered runtime was available in this repository iteration, so no EXE/demo verification is claimed.
- Native Chaos movement/drivetrain roadmap items remain open until the authored Fieldmaster rig and wheel/suspension behavior pass actual UE runtime acceptance.
