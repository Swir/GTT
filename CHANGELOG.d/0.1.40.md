# GTT 0.1.40 — Packaged Roadside Dispatch Persistence + Save/Load Evidence

## Added
- Added an opt-in packaged Farm Cargo evidence route for the 0.1.39 roadside dispatch sidecar. The route performs real primary `SaveProgress()` / `LoadProgress()` roundtrips while the voluntary roadside transaction remains on disk.
- Added a guarded `ReloadCheckpointForRuntimeEvidence()` hook that is available only with `-GTTFarmCargoDispatchPersistenceScenario`. It re-arms the production sidecar loader without manufacturing a service, cash mutation, vehicle identity or quote.
- Added positive TOW persistence proof: sidecar checkpoint, primary save/load, exact `PersistentVehicleId`, locked quote and remaining ETA restore, then restored cancellation with no charge.
- Added fail-closed Wanted proof: a saved tow sidecar is reloaded while Wanted is active, rejected by the production restore path, deleted and proven not to charge or steal Farm Cargo authority.
- Added positive PATCH persistence proof: sidecar checkpoint, primary save/load, exact vehicle + locked quote + ETA restore, no charge before arrival, then exactly one production charge equal to the locked quote.
- Added continued Farm Cargo proof after the restored patch: running timer, non-improving cargo integrity, wrong-vehicle rejection, Hill Farm relay, North Wood Yard delivery, one payout/completion/reputation result and final primary save.
- Added `Scripts/evaluate_farm_cargo_dispatch_persistence_runtime.ps1`, producing `FARM_CARGO_DISPATCH_PERSISTENCE_RUNTIME.json` with schema `gtt.farm-cargo-dispatch-persistence-runtime.v1` only from packaged runtime markers.
- Added a dedicated source verifier, CI workflow and an 80+ scenario playtest plan.

## Release-pipeline hardening
- Win64 package evidence now defaults to 0.1.40, carries the new persistence scenario through the smoke command line, extends the deterministic runtime window and retains the new manifest in success/failure bundles.
- `DEMO_TECHNICAL_GATE.json` advances to **schema 12** and now requires the dispatch-persistence manifest, matching commit SHA, positive locked quotes, exact-vehicle continuity, no-charge Wanted invalidation, restored patch single-charge proof and one authoritative cargo completion.
- Fixed the final ZIP SHA256 step to hash the ZIP path itself rather than attempting to read a nonexistent `.FullName` property from a PowerShell string.

## Verification truth
- Roadmap truth remains **125/130 (96.2%)**. This milestone strengthens source wiring and the future packaged evidence gate; it does not close any runtime/art checkbox by itself.
- Source CI can verify the SaveGame/evidence contracts, release gate and SWIR Visual Report v3 presentation, but it **does not prove** an Unreal Engine 5.8 compile, packaged Win64 execution, generated PASS persistence manifest, Native Chaos/trailer runtime acceptance, rendered visual acceptance or Demo Release readiness.
- A qualifying Windows x64 + Unreal Engine 5.8 runner must execute the exact candidate before schema-12 runtime evidence can be accepted.
