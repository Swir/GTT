# 0.0.62 — Native Authored Wheel & Suspension Acceptance

- Hardened the canonical Native Chaos wheel contract so validation now checks not only wheel classes/bones but the authored wheel defaults that actually define radius, width, suspension travel, spring rate, damping, friction, steering, drive, brake and handbrake behavior.
- Bound the contract directly to `FGTTChaosVehicleSpec`, preventing the Native Fieldmaster from silently drifting away from its canonical front/rear suspension and tire configuration.
- Extended runtime physics acceptance so an active Native Fieldmaster continuously re-validates the authored wheel/suspension contract; a sustained invalid setup now enters the existing safe legacy fallback instead of remaining active with a broken Chaos configuration.
- Added `NATIVE_WHEEL_SETUP_EVIDENCE` telemetry containing front/rear wheel classes, radii, suspension raise/drop travel, spring rates and damping ratios alongside existing physics/contact evidence.
- Kept ABS and Chaos built-in traction control disabled because GTT deliberately owns traction/stability intervention in its shared gameplay controllers; acceptance now verifies this ownership boundary explicitly.
- Added a dedicated playtest and Project sanity gate for the authored wheel/suspension milestone.

## Limitations / next
- Repository CI verifies source contracts and cannot prove actual runtime suspension compression, tire force or packaged vehicle motion.
- The roadmap remains 125/130. `Dedicated native Chaos wheeled tractor movement` and `Dedicated native Chaos drivetrain/suspension/wheel setup` stay open until a real UE 5.8/Win64 runtime demonstrates correct wheel state, suspension travel and stable packaged driving.
