# GTT 0.1.22 — Ranger road stops, roadside search and flee escalation

This milestone turns the 0.1.21 wildlife-enforcement handoff into a more physical vehicle encounter. Alert-2+ game-warden pursuit now distinguishes compliance from escape instead of resolving every encounter through the same proximity citation.

## Vehicle road-stop state machine

- Rangers issue a single visible `WARDEN ROAD STOP` order when an alert-2+ player vehicle enters the enforcement radius.
- The system recognizes legacy `AGTTVehicleBase`, native Fieldmaster and native Rattleback/Mulebox pawns, so the enforcement rule follows the active fleet migration instead of supporting only one physics path.
- A compliant driver must reduce speed to 2.5 km/h or less, allow the ranger inside the roadside-search radius and hold position continuously for 2.25 seconds.
- The old proximity citation is suppressed while a vehicle stop is active, preventing a ranger from resolving the incident through a moving vehicle.
- Stopping outside final search range does not count as fleeing; the ranger is allowed to approach and complete the search.

## Search, seizure and surrender consequence

- A completed roadside search reuses `AGTTGameMode::TryRangerCitation`, keeping the existing fish confiscation, fine and wildlife-alert clearing behavior authoritative.
- Rural contraband seizure reuses `UGTTRuralEconomySubsystem::ConfiscateContraband`, clearing the same persistent inventory/value produced by forest poaching instead of creating a second road-stop inventory.
- Player feedback reports whether contraband was seized and its lost fence value.
- No new SaveGame fields are introduced because the stop itself is an encounter state, while the affected inventories/wanted state already have authoritative persistence paths.

## Flee escalation into the existing police system

- The stop gives a 7-second compliance window. After that window, movement at 8 km/h or faster is treated as deliberate evasion.
- Evasion adds a bounded 45 wanted heat through the existing `UGTTWantedComponent`, producing a real police consequence without a second police meter.
- The escalation is one-shot for the wildlife incident. Ranger repath ticks cannot repeatedly stack the +45 heat.
- Alert-3 warden radio handoff from 0.1.21 remains independent and continues to use the same wanted system.
