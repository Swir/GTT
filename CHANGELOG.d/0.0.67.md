# GTT 0.0.67 — Native Road Fleet Collision & Wheel-State Control

## Added

- Native Rattleback 82 and Mulebox 1200 now read all four Chaos `FWheelStatus` records during active takeover.
- Shared road-fleet runtime traction risk uses wheel contact loss, slip/skid, slip magnitude/angle, suspension travel spread, tire integrity and tire tuning.
- Risk now actively limits throttle, adds progressive brake assist and reduces steering authority in severe wheel-state events.
- Native road vehicles now receive collision damage through `NotifyHit`, using vehicle speed plus impulse-equivalent speed with a damage cooldown.
- Severe impacts damage tire integrity as well as body condition.
- Loaded Mulebox cargo increases impact severity through a payload-inertia multiplier, tying crashes into the existing legal cargo/reward loop.
- Reaching zero condition causes an immediate Native breakdown: throttle and steering are cut and full braking is requested.
- Added `NATIVE_ROAD_WHEEL_STATE_EVIDENCE`, `NATIVE_ROAD_IMPACT_DAMAGE` and `NATIVE_ROAD_BREAKDOWN` runtime evidence.
- Collision/tire state is immediately mirrored to the existing legacy vehicle so garage, workshop, save/load and farm-job systems keep one persistent source of truth.

## Verification

- Added `Scripts/verify_native_road_damage_control.py` and wired it into Project sanity.
- Added `Docs/PLAYTEST_0.0.67.md` covering baseline driving, wheel-state intervention, collision persistence, breakdown, loaded Mulebox consequences and fallback regression.
- The verifier also recalculates the roadmap checklist/dashboard contract rather than accepting a hand-written percentage.

## Known limitation / Demo status

This milestone is source/runtime implementation and CI-contract work. It is **not** proof of a compiled Unreal Engine 5.8 Win64 game. A Demo Release remains blocked until a real Win64 package is produced, the packaged EXE passes runtime smoke testing, visual acceptance is completed, relevant CI is green, and no demo-critical blockers remain.
