# GTT 0.1.0 — Mission-Aware Fleet Dispatch & Vehicle Loadouts

## Added
- Mission-aware fleet readiness for `FarmCargo`, `HeavyHaul`, `TimberHaul`, `FieldMowing`, and road-oriented work. Each contract can now evaluate the actual assigned vehicle's condition, fuel, tire integrity, body health, service state, garage slot, and expected prep cost before work begins.
- Persistent per-role garage loadouts for `TRACTOR`, `ROAD`, and `CARGO`. Dispatching a vehicle now sets both the active vehicle and the mission loadout for that vehicle's role.
- Save schema v7 fields for tractor, road, and cargo loadout vehicle IDs, including automatic migration/fallback for pre-v7 saves while retaining v5 structural-damage and v6 active-dispatch compatibility.
- Player-facing mission readiness states: `READY`, `CAUTION`, `SERVICE REQUIRED`, and `UNAVAILABLE`, with exact garage slot and service/prep estimates.
- Heavy-haul and mowing safety gates that refuse to start when the required tractor loadout is unavailable or critically unfit. Farm cargo and timber remain flexible sandbox jobs but warn when the preferred cargo loadout needs service.
- Garage `LOADOUT` presentation so the office and numbered bays identify which vehicles are the persistent mission choices for their roles.
- `PLAYTEST_0.1.0.md` and `verify_mission_fleet_loadouts.py` covering loadout persistence, mission readiness, job integration, migration, existing role rewards, and roadmap style-lock integrity.

## Changed
- Farm cargo uses the same authoritative fleet assessment as the garage instead of only reporting whether Mulebox is globally active; the existing Mulebox payout bonus remains tied to actually using the cargo van.
- Heavy haul checks the persistent tractor loadout before the existing physical Fieldmaster-near-trailer requirement, preventing a severely damaged/empty tractor from silently starting a contract it cannot reasonably complete.
- Rural timber now exposes cargo-loadout readiness before pickup, while mowing applies a hard tractor readiness check before the existing physical tractor requirement.
- Garage dispatch remains $15, still obeys police/game-warden locks, still preserves damage/fuel/tuning, and now atomically updates the matching role loadout before `SaveProgress()`.
