# 0.0.43 — Win64 Runtime Evidence Gate — 2026-09-13

## Added
- Dedicated self-hosted Windows x64 / Unreal Engine 5.8 workflow that packages a real Win64 build, validates the cooked archive, launches packaged `GTT.exe` and publishes a verification bundle only after the runtime smoke gate passes.
- `smoke_test_windows.ps1` with a minimum-alive runtime check and machine-readable `RUNTIME_SMOKE.json` containing exact commit, runner, launch arguments and observed survival duration.
- Verified artifact bundle containing the release ZIP, ZIP SHA-256, `BUILD_INFO.json`, `PACKAGE_VALIDATION.json` and `RUNTIME_SMOKE.json`.
- `PLAYTEST_0.0.43.md` separating automated headless executable evidence from the rendered visual acceptance still required before a public demo.
- `verify_win64_evidence_pipeline.py` wired into Project sanity so the evidence contract cannot silently disappear or falsely close the final roadmap tasks.

## Changed
- Windows packaging now defaults to milestone version 0.0.43 and stamps an evidence-schema version into `BUILD_INFO.json`.
- The demo/release gate now has explicit machine evidence for build/package/startup, while visual quality remains a separate required rendered review rather than being inferred from a `-nullrhi` smoke test.
- Roadmap remains exactly 125/130 (96.2%): the workflow is implemented, but `Full Win64 CI/build runner`, `Full Unreal compile + packaged Win64 smoke test` and Native Chaos runtime tasks stay open until an actual UE 5.8 runner executes them successfully.

## Limitations / Next
- This source milestone does not claim a real Win64 package has been produced or launched yet; that requires a connected runner labeled `self-hosted`, `windows`, `x64`, `unreal-5.8` with Unreal Engine 5.8 installed.
- A successful headless runtime smoke is not visual approval. Public demo readiness still requires a normal rendered packaged run, screenshots/video inspection, and gameplay/visual acceptance.
- The next major package should combine the first successful Win64 evidence run with authored Fieldmaster skeletal/Physics Asset runtime activation, or continue removing the highest-impact visible greybox debt if the runner remains unavailable.
