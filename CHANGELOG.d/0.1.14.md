# GTT 0.1.14 — Native Chaos Runtime Acceptance & Win64 Build Forensics

## Added
- Added `Scripts/preflight_win64_unreal.ps1`, a fail-fast UE 5.8/Win64 runner gate that writes `WIN64_PREFLIGHT.json` before packaging starts.
- The preflight records exact engine/toolchain readiness: Windows host, RunUAT, UnrealEditor-Cmd, UnrealBuildTool, UE `Build.version`, GTT `EngineAssociation`, Chaos Vehicles plugin, runtime module, Git/Git LFS, MSVC, Windows SDK and free disk capacity.
- Added durable `BUILD_ATTEMPT.json` evidence around Unreal Automation Tool execution so a failed compile/cook/package attempt is distinguishable from a runner that never reached UAT.
- Added a dedicated 0.1.14 source-contract workflow covering the Win64 evidence path and the existing dedicated Fieldmaster Chaos movement contract.
- Added explicit failure-diagnostic artifact upload paths for both the technical-candidate and release packaging workflows.

## Changed
- `package_windows.ps1` now defaults to 0.1.14, requires a passing preflight before deleting/creating the archive, captures UAT result/error metadata, and embeds both preflight and build-attempt evidence into successful packages.
- `validate_windows_package.ps1` now rejects packages that do not carry PASS schema-v2 preflight and UAT evidence before it accepts the executable/cooked-container structure.
- The technical-candidate workflow now treats `WIN64_PREFLIGHT.json` and `BUILD_ATTEMPT.json` as first-class evidence alongside runtime smoke, deterministic scenario, gameplay smoke and demo technical gate.
- The release workflow runs the same source contract and preflight instead of relying on a single `RunUAT.bat` existence check.
- Windows release documentation now separates runner readiness, UAT build evidence, package validation, runtime smoke and visual acceptance.

## Fixed during milestone verification
- Project sanity correctly caught the older 0.0.94 demo-candidate verifier pinning the package-evidence workflow's default version. The regression gate now keeps all original scenario-v11/33 evidence checks while accepting the intentional 0.1.14 workflow default.

## Acceptance boundary
- No roadmap checkbox is closed by this source-only milestone.
- `Full Win64 CI/build runner`, `Full Unreal compile + packaged Win64 smoke test`, dedicated native tractor runtime acceptance and native drivetrain/suspension/wheel acceptance remain open until a real UE 5.8 Windows runner executes the required workflows and produces matching runtime evidence.
- No Demo Release is authorized by these changes alone.
