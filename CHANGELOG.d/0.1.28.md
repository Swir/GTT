# GTT 0.1.28 — Exact Farm Cargo Authority & Packaged Vertical-Slice Evidence

## Gameplay / integration

- Farm Cargo now locks the contract to the **exact loaded vehicle** at the Feed Depot. A different healthy vehicle parked at Hill Farm or North Wood Yard can no longer satisfy the handoff.
- The same authority validates both yard distance and the loaded actor's real speed: accepted handoffs require the exact cargo vehicle within **750 cm** and at or below **3.0 km/h**.
- Feed Depot pickup, Hill Farm relay and North Wood Yard completion all route through the same `UGTTFarmCargoAuthoritySubsystem`, while payout, logistics reputation, Wanted state and saving stay in their existing authoritative systems.
- Rejected pickup actions roll back the temporary load lock so a failed interaction cannot strand a contract on the wrong actor.

## Packaged runtime acceptance

- Added the opt-in `-GTTFarmCargoScenario` packaged runtime exercise. It drives the real Farm Cargo terminals/director through contract acceptance, exact-vehicle load lock, a deliberate wrong-vehicle/loaded-vehicle-away rejection, accepted handoff, payout/logistics progression and save.
- Added `smoke_test_farm_cargo_windows.ps1` with an isolated user directory and a dedicated `GTT_FARM_CARGO_RUNTIME.log` so the evidence pass cannot contaminate the normal demo smoke save.
- Added `evaluate_farm_cargo_runtime.ps1`, producing `FARM_CARGO_RUNTIME.json` only after the exact vehicle ID, rejection distance, accepted handoff speed/distance, positive cash delta, completed-run delta and save markers are verified.
- The Win64 technical candidate gate now requires `FARM_CARGO_RUNTIME.json`; `DEMO_TECHNICAL_GATE.json` advances to schema 7. This is a stricter gate, not a claim that a qualifying UE 5.8 Win64 run has happened.
