# 0.1.57 — Fieldmaster native implementation ownership hardening

- Remove the duplicate `GTTFieldmasterNativePawnRuntime.cpp` translation unit that redefined hit, mud, impact-damage and rear-hitch methods already owned by `GTTFieldmasterNativeEnvironment.cpp` and could block a real Unreal/Win64 link with duplicate symbols.
- Make the native-link verifier scan the complete Fieldmaster native translation-unit surface and require each protected out-of-line method to have exactly one repository definition in the canonical environment implementation.
- Move the condition-scale verifier to that canonical implementation and explicitly fail if the obsolete duplicate runtime unit returns.
- Extend the 0.1.57 packaged witness contract to require successful compile/link of the single Fieldmaster native implementation surface; this source hardening does not claim the Win64 runtime gate.
