# GTT 0.0.71 — Native Roadside Recovery & Police Impound

## Added
- Automatic stranded-vehicle detection for active Native Rattleback 82 and Mulebox 1200 using the real migration snapshot: condition, fuel, tire integrity, body-zone damage and detached panels.
- A seven-second roadside-response window for genuinely disabled, nearly stationary player vehicles instead of a debug reset or silent respawn.
- Economy-backed recovery pricing that combines tow distance, mechanical condition, tire damage and the existing Native body-panel workshop surcharge.
- Police impound escalation when a vehicle becomes stranded at wanted level 2+, including an impound/safety-service fine, wanted clearance and workshop delivery.
- Wanted level 1 blocks civilian roadside assistance until the search state clears, preventing recovery from becoming an escape exploit.
- Workshop handoff reuses `ApplyNativeWorkshopService()` and therefore restores the same condition/fuel/tire/body state already synchronized through the legacy garage/save mirror.
- Runtime evidence logs: `NATIVE_ROADSIDE_RECOVERY_ARMED`, `NATIVE_ROADSIDE_RECOVERY_BLOCKED`, `NATIVE_ROADSIDE_RECOVERY_DENIED`, `NATIVE_ROADSIDE_RECOVERY_COMPLETE`, `NATIVE_POLICE_IMPOUND_ARMED` and `NATIVE_POLICE_IMPOUND`.

## Gameplay impact
- A catastrophic crash, empty tank, destroyed tires or severe multi-panel body failure can now end a drive with a real economic consequence instead of leaving the player permanently stranded.
- Damage from 0.0.67–0.0.70 now feeds a complete loop: crash -> degraded handling/breakdown -> wanted-aware recovery/impound -> fee -> workshop repair -> synchronized garage/save state.
- Police pursuits gain a meaningful vehicle consequence: getting disabled while heavily wanted can end in an expensive impound rather than a free reset.

## Validation / limitations
- Project sanity verifies the subsystem contract, economy/wanted/workshop integration, recovery evidence tokens and the unchanged SWIR Roadmap Standard v1 dashboard.
- Roadmap remains 125/130 (96.2%); this milestone does not claim Native Chaos runtime acceptance, final authored trailer assets or a Win64 runner.
- Full Unreal Engine 5.8 Win64 compile/package/runtime smoke and rendered visual acceptance are still required before any Demo Release can be published.
