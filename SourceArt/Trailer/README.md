# GTT Farm Trailer Source Art

`GTT_FarmTrailer_Rig.gltf` is original project-owned source art for Grand Theft Tractor. It is intentionally stored as a self-contained text glTF so the geometry/rig can be reviewed, reproduced and verified without committing a fabricated Unreal `.uasset`.

The source contract is generated by `Scripts/generate_gtt_farm_trailer_gltf.py` and requires `body`, `wheel_l`, `wheel_r`, `socket_hitch`, `socket_cargo`, `socket_axle_l` and `socket_axle_r`.

This folder is **not** packaged-runtime proof. UE 5.8 import, Physics Asset setup, final Unreal sockets, runtime towing evidence and rendered visual acceptance remain required before the authored-trailer roadmap gate can close.
