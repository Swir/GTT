# GTT 0.1.60 — Authored Trailer Source Rig Acceptance

This milestone replaces “nothing to import” with a deterministic, project-owned trailer source rig. It does **not** close the roadmap checkbox by source inspection alone.

## Source asset contract

- `SourceArt/Trailer/GTT_FarmTrailer_Rig.gltf` is a self-contained glTF 2.0 source asset.
- The file is generated byte-for-byte by `Scripts/generate_gtt_farm_trailer_gltf.py`.
- Required skeletal joints: `body`, `wheel_l`, `wheel_r`.
- Required authored anchors: `socket_hitch`, `socket_cargo`, `socket_axle_l`, `socket_axle_r`.
- Body, drawbar, rails/fenders and both wheels are original project geometry; no commercial-game mesh, texture, logo or other protected asset is used.
- Two materials are authored in the source: `GTT_TrailerPaint` and `GTT_Tire`.

## Source verification

Run:

```bash
python Scripts/generate_gtt_farm_trailer_gltf.py --check
python Scripts/verify_v0_1_60_authored_trailer_source_rig.py
```

Both must pass without modifying the tracked asset.

## Unreal Editor import acceptance — still required

The roadmap item `Authored skeletal trailer wheel assets and final hitch sockets` remains open until all of the following are proved inside the real UE 5.8 project:

- import the source rig as a skeletal trailer asset under the project-owned trailer content path;
- preserve the `body`, `wheel_l` and `wheel_r` hierarchy;
- create/confirm final Unreal sockets corresponding to the four authored `socket_*` anchors;
- create a Physics Asset with a stable body and independently usable wheel bodies;
- wire `AGTTFarmTrailer` to the authored asset without relying on Engine BasicShapes for the accepted visual path;
- verify empty and loaded ground clearance, both wheel contacts, hitch alignment and articulation;
- verify wheel loss/repair and breakable-hitch behavior still use the authoritative trailer state;
- tow the loaded authored trailer behind the Native Fieldmaster and stop under control;
- produce the existing `AUTHORED_TRAILER_RUNTIME_EVIDENCE` and `NATIVE_TRAILER_SCENARIO_COMPLETE ... result=PASS` markers from the exact packaged candidate;
- pass `Scripts/evaluate_authored_trailer_runtime.ps1` on the same Win64 build SHA;
- visually review the exact rendered candidate and reject visible clipping, floating wheels, broken hitch placement or obvious placeholder presentation.

Only that UE 5.8 packaged/runtime/visual proof may close the roadmap checkbox.
