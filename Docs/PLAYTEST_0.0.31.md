# GTT 0.0.31 — Original Radio Audio Playtest

This milestone turns the existing four-station radio framework into an audible, original in-game system. All program audio is generated from project-owned synthesis code at runtime; no third-party music, samples, stems, logos or copyrighted recordings are shipped.

## Core acceptance

1. Enter any drivable vehicle and cycle the radio with `R` / the mapped controller action.
2. Verify `GRAVEL FM`, `BARNBEAT 96`, `RUST & DIESEL` and `NIGHT SHIFT` each produce audible program audio rather than metadata-only track names.
3. Confirm the HUD station/track title matches the active generated program.
4. Let one 36-second program finish and verify the next title starts with no manual input.
5. Cycle through all four stations and then to `RADIO OFF`; audio must stop immediately.
6. Exit a vehicle, enter another owned vehicle and verify the player radio component remains usable.

## Sound identity matrix

- **GRAVEL FM** — slower melodic rural/electronic bed with softer bass and harmonic lead.
- **BARNBEAT 96** — faster pulse/saw dance pattern with stronger four-on-the-floor kick and offbeat accents.
- **RUST & DIESEL** — saturated, rougher mid-tempo waveform intended to suit workshop/driving gameplay.
- **NIGHT SHIFT** — low-BPM atmospheric pad/lead bed with restrained percussion.

The 16 existing fictional track names are retained. Each station/title pair is deterministically seeded, so titles have stable musical identities between sessions while remaining fully generated by GTT code.

## Settings integration

1. Set `MasterVolume` to 0 and verify radio becomes silent.
2. Restore master volume, set `RadioVolume` to 0 and verify only radio is silent.
3. Set both values to partial levels and verify the effective gain follows `MasterVolume * RadioVolume`.
4. Change audio volume while a station is playing; the component refreshes gain without requiring a station change.

## Regression

- vehicle throttle/steering/exit controls remain responsive while the radio plays;
- radio station cycling still updates the existing HUD display line;
- save/load, wanted, missions and vehicle damage are unaffected;
- no external audio files, copyrighted music or third-party sample packs are required for a clean checkout.

## Runtime/packaging boundary

Repository sanity verifies the source integration, deterministic synthesis path, settings linkage and roadmap accounting. A real UE 5.8 audio-device test and packaged Win64 smoke test are still required before release acceptance. This milestone does **not** claim that a packaged EXE has been audio-smoke-tested on the current Linux-hosted sanity runner.
