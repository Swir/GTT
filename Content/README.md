# Content folder

Unreal `.uasset` and `.umap` files belong here and are tracked through Git LFS.

Planned top-level content folders:

- `Blueprints/`
- `Characters/`
- `Vehicles/Tractors/`
- `Vehicles/Cars/`
- `World/Maps/`
- `World/Props/`
- `Missions/`
- `AI/`
- `UI/`
- `Audio/`
- `Data/`

Do not commit Marketplace or third-party assets unless their license allows redistribution in this repository.
